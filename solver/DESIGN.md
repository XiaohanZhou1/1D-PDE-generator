## 1. 目标与范围

**目标。** 输入一个一维偏微分方程（PDE）和一个指定的行波（travelling wave），快速输出这个行波的谱稳定性（spectral stability）标签。

**已确定的范围。**

| 项 | 决定 |
|---|---|
| 研究对象 | 只考虑行波。标签属于"波"，不属于"方程" |
| 输入 | 指定路径下的一个 SymPy 文件。两种用法：(a) 方程、参数值、两端状态、波的类型，得到这一个波的标签；(b) 只有方程和参数值，求解器自己搜索波，得到一份清单（2.11 节） |
| 求波 | 用户给两端状态和类型；求解器用边值问题求出波 |
| 推导 | 全部由程序完成（符号加数值），不使用大模型 |
| 输出 | 每个波一条记录：STABLE / UNSTABLE / UNCERTAIN，附波、空间、证据 |
| 产出的边界 | 唯一的产出是每个波的标签。不做参数扫描、分岔图、特征值表等其他分析（2026-11-24）。证据只留在记录文件里 |
| 可信等级 | 数值结论，不是证明 |
| 速度 | 每个波秒级；在精度足够的前提下用最粗的分辨率 |
| 判定方式 | 两轮：第一轮快速；第二轮只审计非 UNSTABLE 的结果 |

**最终要求（用户 2026-11-24）。** 凡是覆盖的方程类别，给定方程和初始条件，输出行波的谱稳定性标签。初始条件指：参数值；对守恒律和色散型方程，另有两端状态；对色散型的孤立波，另有波速。
只考虑行波 u = U(x − ct)，波速可以为零。旋转对称的方程只取频率为零的波（2.16 节）。

**不在范围内。** 周期波列；两端不是常数状态的波；显含 x 或 t 的方程；高于一维的扰动。

## 2. 数学规格

本节只陈述数学对象和定义，不含任何数值方法。

### 2.1 方程类 L（局部方程组）

未知量 u(x,t) ∈ ℝⁿ。方程为

  ∂ₜu = G(u, ∂ₓu, …, ∂ₓᵐu; θ)，

其中 θ 是参数，G 光滑，且不显含 x 和 t。记 mⱼ 为分量 uⱼ 出现的最高空间导数阶数。

假设 (Q)：G 对各分量的最高阶导数是仿射的（拟线性）。

### 2.2 行波

行波是形如 u(x,t) = U(z)，z = x − ct 的解。它满足剖面方程

  E(U, U′, …; c) := G(U, U′, …) + cU′ = 0。

两端状态 u₋ = U(−∞)，u₊ = U(+∞) 是常数，且 G(u±, 0, …, 0) = 0。
波前（front）：u₋ ≠ u₊。脉冲（pulse）：u₋ = u₊。

**一阶形式。** 分量 j 在剖面方程中的阶数为 μⱼ = max(mⱼ, 1)。状态向量 Y 由 Uⱼ 及其直到 μⱼ − 1 阶的导数组成，维数 N = Σμⱼ。
记 T 为各分量的最高阶导数。由假设 (Q)，E = H(Y, c)·T + r(Y, c)。

假设 (H)：沿着波 det H ≠ 0。于是 Y′ = f(Y; c)。

假设 (E)：平衡点 Y± 是双曲的。

**速度的自由度。** 记 k₋ᵘ 为 Y₋ 的不稳定流形维数，k₊ˢ 为 Y₊ 的稳定流形维数，ι = k₋ᵘ + k₊ˢ − N。
- ι = 0：速度是孤立的，c 是未知量。
- ι = 1：存在连续的一族波，c 必须给定。
- 其他情形不在 M1 范围内。

**波的分支与折点。** 设 θ₁ 是一个参数。满足剖面方程的三元组 (U, c, θ₁) 在一般情形下构成一条光滑曲线，称为波的分支（branch）。记 s 为沿分支的弧长。分支上 dθ₁/ds = 0 的点称为折点（fold）。
- 在折点的一侧，同一个 θ₁ 对应两个不同的波；另一侧没有波。
- 沿分支对剖面方程求导，在折点处得到 𝓛U_s = −c_s U′（𝓛 见 2.3 节）。所以折点处零特征值的代数重数至少为 2。
- 推论：沿分支经过一个非退化的折点时，有一个实特征值穿过零点。这是第 5 节的一项一致性检验。

### 2.3 线性化与特征值问题

设扰动为 u = U(z) + e^{λt} p(z)。线性化给出

  λp = 𝓛p，  (𝓛p)ᵢ = Σⱼ Σₖ a⁽ᵏ⁾ᵢⱼ(z) ∂_zᵏ pⱼ，  a⁽ᵏ⁾ᵢⱼ = ∂Eᵢ/∂Uⱼ⁽ᵏ⁾（在波上取值）。

写成一阶方程组：P′ = (M₀(z) + λM₁(z)) P，P ∈ ℂᴺ。
当 z → ±∞ 时，M(z, λ) → M±(λ)。

### 2.4 谱、稳定性、标签的语义

函数空间：不加权的 L²(ℝ; ℂⁿ)。

**本质谱（essential spectrum）。** 它的边界由色散关系给出：

  det( Σₖ A±ₖ (iκ)ᵏ − λ ) = 0，κ ∈ ℝ，

其中 A±ₖ 是 a⁽ᵏ⁾ 在两端状态的值。记 s_ess 为这些曲线上 Re λ 的上确界。
s_ess 与 c 无关，因为 c 只贡献纯虚数 icκ。

**部分抛物方程组（partly parabolic system）。** 设最高阶数为 2。记 P 为含二阶导数的分量集合，H 为不含二阶导数的分量集合。上标表示系数矩阵的相应子块。
结构条件 (S1)：H 的方程里不出现二阶导数，即 A₂ᴴᴾ = 0。
此时 κ → ∞ 时 H 对应的色散支保持有界：

  λ = iκσ + μ + O(1/κ)，

其中 σ 是 S = A₁ᴴᴴ 的特征值（须为实数），μ 是 B = A₀ᴴᴴ − A₁ᴴᴾ(A₂ᴾᴾ)⁻¹A₁ᴾᴴ 限制在 σ 的特征子空间上的特征值。
所以 s_ess 可能只在 κ → ∞ 时被逼近，而不在有限的 κ 处取到。
限制：当 c = 0 且 H 非空时，本质谱还含有 A₀ᴴᴴ(z) 沿波的全部特征值，不只取决于两端状态。这个情形里 H(Y, c) 奇异，不在本节范围内。

**区域 Ω。** 复平面去掉上述曲线后，含大正实数的那个连通分支。
假设 (C)：在 Ω 上，M₋(λ) 和 M₊(λ) 的不稳定子空间维数相等，记为 k。

**点谱（point spectrum）。** Ω 内的特征值是 Evans 函数 D(λ) 的零点，重数相同。D 在 Ω 上解析。

**平移模。** 𝓛U′ = 0。所以当 0 ∈ Ω 时 D(0) = 0。

**标签的定义。**

| 标签 | 条件 |
|---|---|
| UNSTABLE | s_ess > 0；或 D 有 Re λ > 0 的零点 |
| STABLE | s_ess < 0；λ = 0 是 D 的单零点；D 没有其他 Re λ ≥ 0 的零点 |
| 两者都不是 | s_ess = 0；零点不是单的；有非零的纯虚零点。M1 对这些情形输出 UNCERTAIN |

完整的陈述是："这个波，在这组参数下，在不加权的 L² 中，按上述约定，谱稳定。"

**带限定词的 STABLE（用户 2026-11-24 确定）。** s_ess = 0 时上面的 STABLE 不可能成立。两种情形下给出放宽的标签：
- "STABLE（代数衰减）"：守恒律，见 2.14 节；
- "STABLE（中性）"：色散型和无耗散的方程，见 2.15 节。

限定词总是与标签一起打印。UNSTABLE 的含义不变。

**搜索区域的界。** 设所有 μⱼ = 2，且 A₂(z) 的对称部分满足 sym A₂ ≥ d > 0。记 t = ‖p′‖/‖p‖，A₁ = S₁ + K₁（对称部分加反对称部分）。对 λ‖p‖² = ⟨p, 𝓛p⟩ 分部积分，取实部和虚部，得

  Re λ ≤ −d t² + (b_K + d₁) t + c₀ + s₁/2，
  |Im λ| ≤ a t² + (b + d₁) t + c₂，

其中各量是沿波的上确界：b_K = ‖K₁‖，b = ‖A₁‖，d₁ = ‖A₂′‖，s₁ = ‖S₁′‖，c₀ = λ_max(sym A₀)，c₂ = ‖skew A₀‖，a = ‖skew A₂‖。
由 Re λ ≥ −δ 得 t ≤ t_max，从而 Re λ > −δ 的全部点谱落在一个有界矩形内。

**部分抛物方程组的界。** 记 p = (p₁, p₂)，p₁ 属于 P，p₂ 属于 H。除 (S1) 外再假设：
- (S2) S = A₁ᴴᴴ(z) 是实对称矩阵；
- (S3) −δ > β，其中 β = sup_z λ_max( sym A₀ᴴᴴ − S′/2 )。

第一步，对 H 的方程与 p₂ 作内积并取实部。由 (S2)，Re⟨Sp₂′, p₂⟩ = −½⟨S′p₂, p₂⟩。记 g = −δ − β > 0，得

  ‖p₂‖ ≤ (α₁‖p₁′‖ + α₀‖p₁‖) / g，  α₁ = sup‖A₁ᴴᴾ‖，α₀ = sup‖A₀ᴴᴾ‖。

所以 p₁ ≠ 0。取 ‖p₁‖ = 1，t = ‖p₁′‖。
第二步，对 P 的方程与 p₁ 作内积。耦合项满足 |⟨A₁ᴾᴴp₂′ + A₀ᴾᴴp₂, p₁⟩| ≤ (γ₁t + γ₁′ + γ₀)‖p₂‖，其中 γ₁ = sup‖A₁ᴾᴴ‖，γ₁′ = sup‖(A₁ᴾᴴ)′‖，γ₀ = sup‖A₀ᴾᴴ‖。于是

  Re λ ≤ −d t² + (b_K + d₁) t + c₀ + s₁/2 + (γ₁t + γ₁′ + γ₀)(α₁t + α₀)/g，
  |Im λ| ≤ a t² + (b + d₁) t + c₂ + (γ₁t + γ₁′ + γ₀)(α₁t + α₀)/g，

其中 d、a、b、… 取自 P 的子块。
- (S4) 有效扩散 d − γ₁α₁/g > 0。

在 (S1)–(S4) 下，Re λ ≥ −δ 的全部点谱落在一个有界矩形内。H 为空时，这就是上一段的界。
(S3) 或 (S4) 不成立时，这个估计不给出界。它是充分条件，不是必要条件。

**高于二阶的方程的界。** 设分量 j 的阶数是偶数 2m_j ≥ 2（每个分量的阶数可以不同），没有约束方程。把半阶数相同的分量归为一组 g。
抛物性条件 (P)：每一组的最高阶系数矩阵满足 (−1)^{m+1} sym A_{2m}^{gg} 正定，最小特征值的下确界记作 d_g。
取 ‖p‖ = 1，τ_j = ‖p_j^{(m_j)}‖，T_g² = Σ_{j∈g} τ_j²。
- 插值：0 ≤ s ≤ m_j 时 ‖p_j^{(s)}‖ ≤ τ_j^{s/m_j}。
- 把 ⟨λp, p⟩ 逐项展开。每一项 ⟨a p_j^{(k)}, p_i⟩ 用分部积分把导数分到两个因子上，使每个因子至多带 m 阶导数；落在系数上的导数给出低一阶的项。
- 最高阶项给出 −d_g T_g²（虚部至多 ‖skew‖·T_g²）。其余各项的模不超过 w·τ_j^α τ_i^β，α + β < 2。
- 同一分量的偶数阶项 (−1)^q⟨a p^{(q)}, p^{(q)}⟩ 是实的，只取它的正部；奇数阶项的实部降一阶：Re⟨a p^{(q+1)}, p^{(q)}⟩ = −½⟨a′p^{(q)}, p^{(q)}⟩。所以 c∂_z 一项不进入实部的界。
- 跨组的项用 Young 不等式拆到两个组上：x^α y^β ≤ (αx^s + βy^s)/s，s = α + β。

结果是

  Re λ ≤ c₀ + Σ_g ( −d_g T_g² + Σ w·T_g^γ )，  |Im λ| ≤ c₂ + Σ_g ( ‖skew‖_g T_g² + Σ w·T_g^γ )，  γ < 2。

每一组的括号对 T_g 有上界，所以 Re λ ≥ −δ 时各 T_g 有界，点谱落在一个有界矩形内。
这个估计不成立的情形：
- 某个分量的阶数是奇数，或者不含空间导数；
- 条件 (P) 不成立；
- 方程 i 里出现分量 j 的高于 m_i + m_j 阶的导数；
- 阶数不同的两个分量在临界阶 k = m_i + m_j 处耦合。

**对角变量替换。** 对任意正的对角矩阵 D，λ(Dp) = (D𝓛D⁻¹)(Dp)。特征值不变，系数矩阵变为 DA_kD⁻¹。
所以上面的界可以对任何一个 D 来做。只要存在一个 D 使 sym(DA₂D⁻¹) 正定，界就成立。
交叉扩散（cross-diffusion）使 A₂ 不对称，它的对称部分可以不定，尽管方程组是抛物的。这时必须先做这个替换。

**奇偶指标（parity index）。** D 可以规范化为在实轴上取实值。设 0 < r₀ < x_max，且 x_max 右侧没有零点。
- 若 D(r₀) 与 D(x_max) 异号，则 (r₀, x_max) 内有奇数个实零点（按重数计），波不稳定。
- 若同号，实零点的个数是偶数（可以是零）。此时没有结论。

### 2.6 子类 F：自由边界

**问题。** 方程 ∂ₜu = G(u, ∂ₓu, ∂ₓₓu) 在 x < s(t) 上成立。在 x = s(t) 处给出：
- Stefan 条件 ds/dt = S(u, ∂ₓu)；
- n_b 个边界条件 B(u, ∂ₓu, ds/dt) = 0。把 Stefan 条件代入后，它们只依赖 u 和 ∂ₓu，记作 B(u, ∂ₓu) = 0。

边界条件的个数由方程的类型决定：
- 有扩散的分量（方程含自身的二阶导数）：各一个条件。条件可以是 Dirichlet 型（只含 u_j）、Neumann 型（只含 ∂ₓu_j）或 Robin 型（两者都含）。
- 无扩散的分量（2.4 节的集合 H）：它的方程对 x 是一阶的。在固定区域里它的特征线速度是 −S_j，S_j 是 ∂_z p_j 的系数（含 c）。特征线在边界处进入区域时（S_j > 0）给一个边界值；离开区域时（S_j < 0）不给条件。
- 典型情形 ∂ₜw = g(u, w)：S = c。边界前进（c > 0）时 w 要一个边界值；边界后退（c < 0）时不要。c = 0 是退化情形，不处理。

x → −∞ 时 u → u₋。

**固定区域。** 令 z = x − s(t)，u(x, t) = v(z, t)。则在 z < 0 上

  ∂ₜv = G(v, v_z, v_zz) + (ds/dt) v_z，

边界固定在 z = 0。

**行波。** v = U(z)，ds/dt = c。U 满足 z < 0 上的剖面方程 E(U; c) = 0，以及 B(U(0), U′(0)) = 0，c = S(U(0), U′(0))，U(−∞) = u₋。
速度的自由度：未知量是 u₋ 的不稳定流形上的 k₋ᵘ 个坐标和 c；z = 0 处有 n_b + 1 个条件。k₋ᵘ = n_b 时速度是孤立的。同一个问题可以有多个行波。

**线性化。** 设 v = U + e^{λt}p，ds/dt = c + ηe^{λt}。则

  λp = 𝓛p + ηU′（z < 0），  ∂B/∂Y · P(0) = 0，  η = ∇S · P(0)，

其中 P 是 p 的一阶形式。
- 特征值问题是半直线上的 𝓛 加一个秩一项。
- 边界固定了波的位置，所以 λ = 0 一般不是特征值。STABLE 的条件是：s_ess < 0，且 Re λ ≥ 0 内没有特征值。此时 s(t) − ct 收敛到一个常数。
- 本质谱只由 u₋ 决定。
- Evans 函数：把 η 当作一个新的状态分量，η′ = 0。扩展后的一阶方程组维数为 N + 1。D(λ) 是 z = 0 处 n_b + 1 个条件在"−∞ 处衰减的解加上 η 方向"上的行列式。

**搜索区域的界（子类 F）。** 分量分成 P（有扩散）和 H（无扩散），p = (p₁, p₂)。取 ‖p₁‖ = 1，t = ‖p₁′‖，e = |η|。
线性化的边界条件把每个 P 分量归为两型之一：
- D 型：p_j(0) = 0；
- R 型：p_j′(0) = −r_j p_j(0)。Neumann 条件是 r_j = 0。

适用条件：
- (F1) 每个线性化的边界条件只含一个分量；
- (F2) 没有约束方程；
- (F3) 2.4 节的 (S1)–(S3) 成立，并且 P 的方程不含 H 分量的导数（A₁ᴾᴴ = 0）；
- (F4) D 型分量与 R 型分量之间在边界处没有交叉扩散：A₂(0) 的 [R, D] 块为零；
- (F5) 没有边界条件的 H 分量（记作集合 F）：S(0) 在 F 上半负定，并且 Stefan 条件不含这些分量。

记号：ψ_P = ‖U_P′‖，ψ_H = ‖U_H′‖，m₂ = sup‖(A₂ᴾᴾ)⁻¹‖，κ_D = |∂S/∂U_D′|，κ_R = |(∂S/∂U − r ∂S/∂U′)_R|。

1. H 分量。能量恒等式多出边界项 ½ p₂(0)*S(0)p₂(0)。有边界值的分量在 z = 0 处为零；其余分量由 (F5) 给出非正的边界项。所以

  ‖p₂‖ ≤ (α₁t + α₀ + ψ_H e) / g，  g = −δ − β。

2. 迹不等式：|p(0)|² ≤ 2‖p‖‖p′‖。所以 |p_R(0)|² ≤ 2t，|p_D′(0)|² ≤ 2t‖p₁″‖。
3. 实部。对 A₂ 和 sym A₁ 的项分部积分，多出边界项 p₁(0)*A₂(0)p₁′(0) + ½ p₁(0)*sym A₁(0) p₁(0)。D 型分量不贡献。R 型分量代入 p′ = −r p，由 (F4)，边界项等于 p_R*[½ sym A₁ᴿᴿ − sym(A₂ᴿᴿ diag r)]p_R，不超过 2σ_b t。σ_b 是这个矩阵最大特征值的正部。所以

  Re λ ≤ −d t² + (b_K + d₁ + 2σ_b) t + c₀ + s₁/2 + γ₀‖p₂‖ + ψ_P e。

4. 虚部。边界项的模不超过 2ρ_b t，ρ_b = ‖A₂ᴿᴿ(0) diag r‖：

  |Im λ| ≤ a t² + (b + d₁ + 2ρ_b) t + c₂ + γ₀‖p₂‖ + ψ_P e。

5. η 分成两部分，e ≤ e_D + e_R：
   - R 型：η_R = (∂S/∂U − r ∂S/∂U′)_R · p_R(0)，所以 e_R ≤ κ_R √(2t)；
   - D 型：η_D = ∂S/∂U_D′ · p_D′(0)，所以 e_D² ≤ 2κ_D² t ‖p₁″‖。由方程，‖p₁″‖ ≤ m₂(|λ| + b t + ‖A₀‖ + γ₀‖p₂‖ + ψ_P e)。
6. 第 1、3、4、5 条合起来得 e ≤ e_max(t)，其中 e_max 按 t^{3/2} 增长。代回实部的不等式，−d t² 最终占优。所以 Re λ ≥ −δ 的点谱落在一个有界矩形内。

说明：
- 没有 H 分量、全部是 D 型时，这就是原来的界。
- r_j > 0 且没有对流项时 σ_b = 0：耗散型的 Robin 条件不放大矩形的实部。
- 迹不等式对指数函数取等号，所以 R 型的界接近最优；D 型的界经过 ‖p″‖，偏大。
- (F1) 不成立的例子：把 ds/dt 代入边界条件后，一个分量的条件里出现了另一个分量。此时没有界。

### 2.7 约束方程：核可化约的非局部项

**化约。** 设方程含卷积 w = K ∗ g(u)，且核 K 的 Fourier 变换是有理函数。则 w 是一个常系数常微分方程的有界解。例：K(x) = (α/2)e^{−α|x|} 时，w″ − α²w + α²g(u) = 0。
把 w 当作新的未知量，这个方程就是一个不含时间导数的约束方程。原方程组变成

  𝔐 ∂ₜu = G(u, ∂ₓu, ∂ₓₓu)，  𝔐 = diag(1, …, 1, 0, …, 0)。

记 D 为有时间导数的分量集合，C 为约束分量集合。

**行波与线性化。** 剖面方程是 E = G + c𝔐U′ = 0，即约束方程里没有 cU′ 项。特征值问题是

  λ𝔐p = 𝓛p。

一阶形式仍是 P′ = (M₀ + λM₁)P，只是 M₁ 中约束分量对应的列为零。Evans 函数的定义不变。

**本质谱。** 色散关系变为 det(Σₖ A±ₖ(iκ)ᵏ − λ𝔐) = 0。消去约束块后，它是 D 上的普通特征值问题：

  λ ∈ spec( Σᴰᴰ − Σᴰᶜ(Σᶜᶜ)⁻¹Σᶜᴰ )，  Σ(κ) = Σₖ A±ₖ(iκ)ᵏ。

条件：Σᶜᶜ(κ) 对所有实数 κ 可逆。这等价于核的 Fourier 变换在实轴上没有极点。

**搜索区域的界。** 记 p 为 D 分量，q 为 C 分量。假设：
- (N1) 约束方程只通过不带导数的项依赖 p；其他方程里不出现 q″。
- (N2) 约束算子是强制的：Re⟨−𝓛ᶜᶜq, q⟩ ≥ (d_c/2)‖q′‖² + ω‖q‖²，d_c > 0，ω > 0。

由约束方程得 ‖q‖ ≤ K₀‖p‖，‖q′‖ ≤ K₁‖p‖，其中 K₀ = α₀/ω，K₁ = α₀√(2/(d_cω))，α₀ = sup‖A₀ᶜᴰ‖。
于是 p 的方程里，耦合项的模不超过常数 Γ = sup‖A₁ᴰᶜ‖·K₁ + sup‖A₀ᴰᶜ‖·K₀。2.4 节的两个不等式右端各加上 Γ，其余不变。

**与积分形式的关系。** 约束形式和积分形式是同一个算子的两种写法，点谱相同。这给出一个独立的对照：直接离散积分形式，不引入辅助未知量（第 5.3 节）。

### 2.8 多脉冲

**对象。** N 脉冲是这样的行波：它依次经过一个基本脉冲（primary pulse）附近 N 次，相邻两次之间的距离为 D₁、…、D_{N−1}。它与基本脉冲属于同一个方程、同一组参数。

**存在的条件。** 设静息态在脉冲后方的主导特征值是一对复数 α ± iβ（α > 0）。则脉冲的尾迹振荡地衰减，像 e^{αz}cos(βz + φ)。这时在基本脉冲附近存在双脉冲，间距取一列离散的值。尾部单调衰减时一般没有这样的多脉冲。

**谱。** N 脉冲在原点附近有 N 个特征值：一个是平移零特征值，其余 N − 1 个是相互作用特征值，大小随间距指数地减小（Sandstede 1998）。其他特征值靠近基本脉冲的特征值。所以基本脉冲稳定时，N 脉冲的稳定性由这 N − 1 个小特征值的符号决定。

**约化。** 考虑两个脉冲，间距为 D。后一个脉冲处在前一个的尾迹里，它的自然速度是 c₁ + σ(D)，c₁ 是基本脉冲的速度。于是

  dD/dt = −σ(D)。

- 允许的间距是 σ 的零点 D_k。
- 相互作用特征值的主阶是 λ = −σ′(D_k)。
- 弱相互作用时 σ(D) ≈ A e^{−αD} sin(βD + φ)。所以相邻零点相距 π/β；相邻的特征值异号，模之比为 e^{−απ/β}。稳定与不稳定的双脉冲交替出现。

σ(D) 的精确定义：把两个脉冲各自钉在指定位置（每个脉冲一个相位条件），在后一个脉冲所在的区域把剖面方程的速度改为 c + σ，σ 是未知量。即求解

  G(U) + (c + σχ(z)) 𝔐U′ = 0，

χ 在后一个脉冲附近为 1，在前一个脉冲附近为 0。σ = 0 时它就是原来的剖面方程。

**N ≥ 3。** 脉冲前方的尾部衰减得比尾迹快得多时，每个脉冲只受它前面那个脉冲的影响。第 j + 1 个脉冲的速度亏损 σ_{j+1} 主要取决于 D_j。约化系统的 Jacobi 矩阵是三角的，特征值是各个间隙的 −σ′(D_j)。所以 N 脉冲稳定，当且仅当每个间隙都是稳定的双脉冲间距（主阶）。

### 2.9 子类 D：时滞

**问题。** ∂ₜu = G(u, ∂ₓu, ∂ₓₓu, u_τ)，u_τ(x, t) = u(x, t − τ)，τ > 0 是常数。

**行波。** u = U(z)，z = x − ct。时滞项变为 U(z + cτ)。剖面方程

  G(U, U′, U″, U(· + cτ)) + cU′ = 0

含 z 方向的平移，平移量依赖未知的 c。τ = 0 时它退回 2.2 节的剖面方程。

**线性化。** 设 u = U(z) + e^{λt}p(z)。时滞项贡献 e^{λ(t−τ)}p(z + cτ)，所以

  λp(z) = 𝓛₀p(z) + e^{−λτ}B(z)p(z + cτ)，  B = ∂G/∂u_τ（在波上取值），

𝓛₀ 是其余各项的线性化。这个问题对 λ 不是多项式，对 z 不是局部的：它不能写成一阶常微分方程组，Evans 函数的构造不适用。
- 平移模仍然存在：p = U′，λ = 0。
- 时滞可以产生新的特征值，包括复根对（振荡型不稳定）。

**本质谱。** 色散关系是

  det( Σₖ A±ₖ(iκ)ᵏ + B±e^{−λτ + iκcτ} − λ ) = 0，κ ∈ ℝ，

对每个 κ 有无穷多个根。s_ess 是所有根的实部的上确界。它与 c 无关：换到静止坐标系 λ = μ + icκ，c 就消掉了。

**标量情形的闭式。** n = 1 且端点处 𝓛₀ 的零阶系数为 A、时滞系数为 k 时，最右的根在 κ = 0 处，为 A + W₀(kτe^{−Aτ})/τ，W₀ 是 Lambert 函数的主支。

**搜索区域的界。** Re λ ≥ −δ 时 |e^{−λτ}| ≤ e^{δτ}，平移算子的模为 1。所以时滞项是有界扰动，模不超过 e^{δτ}·sup‖B‖。2.4 节两个不等式的右端各加上这个常数。

**多个离散时滞。** ∂ₜu = G(u, ∂ₓu, ∂ₓₓu, u_{τ₁}, …, u_{τ_Q})，各 τ_q > 0 是常数。上面各式里的时滞项换成对 q 的和：
- 剖面方程含 U(z + cτ_q)，q = 1, …, Q；
- 线性化：λp(z) = 𝓛₀p(z) + Σ_q e^{−λτ_q} B_q(z) p(z + cτ_q)，B_q = ∂G/∂u_{τ_q}；
- 色散关系：det( Σₖ Aₖ(iκ)ᵏ + Σ_q B_q e^{−(λ − iκc)τ_q} − λ ) = 0；
- 界：有界扰动的模不超过 sup_z Σ_q e^{δτ_q}‖B_q(z)‖。

**分布时滞。** 方程含积分 I(x, t) = ∫ₐᵇ g(s) F(u(x, t − s)) ds，0 ≤ a < b ≤ ∞。g 是核，F 只含被延迟的未知量。
- 行波上 I(z) = ∫ g(s) F(U(z + cs)) ds。
- 线性化的贡献是 (∂G/∂I)(z) ∫ g(s) e^{−λs} F′(U(z + cs)) p(z + cs) ds。
- 色散关系里出现核的 Laplace 变换 ĝ(μ) = ∫ g(s) e^{−μs} ds，取在 μ = λ − iκc 处。
- ĝ 只在核的衰减率 ρ 的右侧有定义（Re μ > −ρ）。指数尾的核在 Re μ = −ρ 处有奇点，那里是本质谱的一部分。所以分析限制在 Re λ > −ρ 内，δ 必须小于 ρ。
- 界：有界扰动的模不超过 sup‖∂G/∂I‖·∫|g(s)|e^{δs}ds·sup‖F′‖。

**指数核的等价形式（线性链）。** g(s) = e^{−s/T}/T 时，w = ∫g(s)u(x, t−s)ds 满足 ∂ₜw = (u − w)/T。原方程等价于一个多一个无扩散分量的局部方程组（2.4 节）。这给出分布时滞的一个独立对照。

### 2.10 子类 N：一般核的卷积

**问题。** ∂ₜu = G(u, ∂ₓu, ∂ₓₓu, V)，V_k(x, t) = ∫K_k(x − y) g_k(u(y, t)) dy，K_k 可积。
2.7 节处理的是 Fourier 变换为有理函数的核。本节不作这个假设（例如高斯核）。

**行波与线性化。** 卷积与平移可交换，所以剖面方程是 G(U, U′, U″, K ∗ g(U)) + cU′ = 0。线性化为

  λp = 𝓛₀p + B(z)·[K ∗ (g′(U)p)](z)，  B = ∂G/∂V。

这是积分-微分方程，不能写成一阶常微分方程组。它对 λ 是线性的。平移模 p = U′、λ = 0 仍然存在。

**本质谱。** det( Σₖ A±ₖ(iκ)ᵏ + B±·K̂(κ)·g′(u±) − λ ) = 0，K̂(κ) = ∫K(s)e^{−iκs}ds。
K̂ 不是常数，所以上确界可以在 κ ≠ 0 处取到（负耦合时的 Turing 型不稳定）。

**搜索区域的界。** Young 不等式给出 ‖K ∗ f‖ ≤ ‖K‖₁‖f‖。所以非局部项是有界扰动，模不超过 sup‖B‖·‖K‖₁·sup‖g′‖。2.4 节两个不等式的右端各加上这个常数。

**局部极限。** 把每个核换成"质量 × δ 函数"，即 V = (∫K)·g(u)，得到一个局部方程。它可以作为求波的同伦起点，但它不一定有相应的波。

**没有扩散项的情形。** ∂ₜu = G(u, V)，方程里不含 u 的任何 x 导数。例：神经场方程 ∂ₜu = −u + K ∗ S(u)；非局部相变方程 ∂ₜu = J ∗ u − u + f(u)。
- 剖面方程是 cU′ + G(U, K ∗ g(U)) = 0。c ≠ 0 时它对 z 是一阶的；c = 0 时它不含导数，是一个积分方程。
- 局部极限 ∂ₜu = G(u, (∫K)g(u)) 是常微分方程，没有行波。所以这里没有同伦的起点。
- 线性化：λp = cp′ + a₀(z)p + Cp，a₀ = ∂G/∂u，Cp = Σₖ oₖ(z)·Kₖ ∗ (iₖ(z)·p)，oₖ = ∂G/∂Vₖ，iₖ = gₖ′(U)。平移模 p = U′、λ = 0 仍然存在。
- 本质谱：端点处的曲线 λ = icκ + eig( a₀± + Σₖ oₖ± K̂ₖ(κ) iₖ± )。κ → ∞ 时 K̂ → 0，曲线不趋向 −∞，而是趋向竖直线 Re λ = Re eig(a₀±)。这个极限算入上确界。
- 驻波（c = 0）时局部部分是乘法算子 p ↦ a₀(z)p。它的全部取值都属于本质谱，所以 s_ess 还要与 sup_z Re eig a₀(z) 取最大。c ≠ 0 时本质谱只由两端决定。
- 驻波的光滑性：c = 0 且 u ↦ G 对 u 不单调时，剖面可以不连续。这种情形 sup_z Re eig a₀(z) ≥ 0，由上一条给出 UNSTABLE 或 UNCERTAIN。

**没有扩散项时搜索区域的界。** 2.4 节的界靠 −d‖p′‖² 一项，这里没有。取 ‖p‖ = 1，记 c₀ = sup_z λ_max(sym a₀)，‖C‖ ≤ Σₖ sup|oₖ|·‖Kₖ‖₁·ιₖ，ιₖ = sup|iₖ|。有三个估计：

(a) 数值域。c∂_z 是反对称的，所以 Re λ ≤ c₀ + ‖C‖。驻波时还有 |Im λ| ≤ sup‖skew a₀‖ + ‖C‖。这给出驻波的完整矩形，对变系数成立。

(b) 由方程得到的衰减。记 wₖ = iₖ·p。由方程，λwₖ = iₖ·(cp′ + a₀p + Cp)。又 K ∗ (i·p′) = K′ ∗ (i·p) − K ∗ (i′·p)。所以

  ‖Kₖ ∗ wₖ‖ ≤ Θₖ/|λ|，  Θₖ = |c|·(TV(Kₖ)·ιₖ + ‖Kₖ‖₁·ιₖ′) + ‖Kₖ‖₁·ιₖ·(sup‖a₀‖ + ‖C‖)，

TV 是核的全变差，ιₖ′ = sup|iₖ′|。另一方面 Re λ − c₀ ≤ ‖Cp‖。合起来，Re λ ≥ −δ 时

  |λ| ≤ Σₖ sup|oₖ|·Θₖ / (−δ − c₀)，

条件是 −δ > c₀。它对变系数成立，但常数偏大。

(c) Fourier 乘子。设局部部分沿波近似为常数：取 a₀ 和 oₖ 沿波的中值 M、ōₖ，R(κ) = (λ − M − icκ)⁻¹。本征函数满足 p = R[(a₀ − M)p + Cp]，所以

  1 ≤ Σₖ sup_κ ‖R(κ)ōₖ‖·|K̂ₖ(κ)|·ιₖ + sup_κ‖R(κ)‖·ρ，  ρ = sup‖a₀ − M‖ + Σₖ sup|oₖ − ōₖ|·‖Kₖ‖₁·ιₖ。

|Im λ| → ∞ 时第一项趋于零（K̂ 衰减），所以 sup‖R‖·ρ < 1 时 |Im λ| 有界。这个界比 (b) 紧，但要求变系数部分 ρ 小。

矩形取三者允许的最小者。(b) 和 (c) 都不成立而波又在移动时，没有界。

### 2.11 只给方程时的搜索范围

"一个方程的全部行波"不是一个可计算的对象：行波可以有无穷多个，也没有算法能保证找全同宿轨道和异宿轨道。只给方程和参数值时，求解器完成的是下面这个有限的任务。

**平衡点。** 常数解 e 满足 G(e, 0, …) = 0。记 s(e) 为以 e 为常数背景时本质谱的上确界（2.4 节的色散关系）。s(e) < 0 的称为稳定平衡点。

**整族的结论。** 若 s(e) > 0，则任何以 e 为一端的行波都有 s_ess > 0，按 2.4 节的定义是 UNSTABLE。这是关于一族波的一个结论，不需要求出其中任何一个波，也不断言这样的波存在。

**候选集合。**
- 每一对稳定平衡点之间的波前。方程在 x → −x 下不变时，一个波与它的镜像算同一个，只列一次。
- 每个稳定平衡点上的脉冲。
- 有自由边界时：以每个稳定平衡点为远端状态的半波。

**输出的含义。**
- 候选被求出：给出这个波的标签。
- 候选没有求出：报告"未找到"。这不是"不存在"。
- 清单不完备。缺少的有：候选集合之外的波（例如多脉冲）；同一对端点之间的其他波（下面的伙伴波除外）；通用猜测达不到的波。

**伙伴波。** 设一个波恰好有一个不稳定特征值，而且它是实的。这样的波可以是折点一侧的不稳定半支（2.2 节）：沿分支过折点，这个特征值穿过零，另一侧的波没有它。所以另一侧可能是一个稳定的波，端点相同，参数相同。


**补齐后的搜索范围（2026-11-24）。** 只给方程和参数值时，下列情形也在候选集合里。
- 临界平衡点（s(e) = 0）。例：没有阻尼的波动方程的全部平衡点；不恢复的无扩散分量。它们可以作端点状态，波的标签按 2.15 节给出。
- 没有阻尼的对时间二阶的方程：波按波速成族，清单里列驻波，作为这一族的代表。对 Lorentz 不变的方程 u_tt = u_xx + f(u)，族内各成员的标签相同。
- 趋向无扩散分量的输运（2.17 节）：候选与普通方程组相同，波速的初值不取零。
- 旋转对称的方程（2.16 节）：只取频率为零的波。旋转分量不为零的平衡点成一圈，不作端点状态；每一圈留一个代表，只用来给脉冲的猜测定方向。频率不为零的波不是行波，不列出。
- 双脉冲：对每个稳定的、尾部振荡的脉冲，列出两个拷贝在最小的 3 个允许间距上的双脉冲（2.8 节）。多脉冲有无穷多个，清单到此为止。不稳定的脉冲的任何多脉冲都不稳定，只给一句整族的结论。

**仍然需要另给条件的情形。**
- 守恒律：每个常数都是平衡点，波不由方程单独决定。必须给两端状态；波速由跳跃条件算出。脉冲没有给波速时取驻波。
- 色散型的孤立波（KdV 型）：静止状态和波速都必须给。波速连续地成族，标签可以随波速改变。

**点名的波（2026-11-24）。** 输入给出波的类型和两端状态（以及已知的波速），不给剖面的猜测。这些条件确定的是一个集合：满足条件的波可以不止一个。
- 波前和半波：两端状态之间的单调过渡作猜测。它失败时，用上面的搜索，只保留类型、两端状态、波速与输入相符的波。
- 脉冲：两端状态相同，猜测还需要一个幅值。守恒律和色散型方程的约化剖面方程（2.14 节）除了静止状态 u₀ 还有别的常数解 v；脉冲的同宿轨道绕过其中一个，幅值与 |v − u₀| 同阶。宽度取静止状态处最慢衰减率的倒数。其他方程用上面的搜索。
- 方程有反射对称 x → −x 时，波与它的镜像是同一个波，镜像也算相符。
- 结论的范围：列出的是找到的波。满足条件的波没有列出，不表示它不存在。



### 2.12 对时间二阶的方程

**问题。** 方程含 ∂ₜₜu。把每个分量的方程对它的最高阶时间导数解出：
- 含 ∂ₜₜu_j 的分量：∂ₜₜu_j = G_j(u, ∂ₓu, ∂ₓₓu, ∂ₜu)；
- 其余分量：∂ₜu_j = G_j，同 2.1 节。

最高阶时间导数的系数必须是常数。不含混合导数 ∂ₓ∂ₜu，没有约束方程。
例：阻尼波方程 τu_tt + γ(u)u_t = u_xx + f(u)。

**行波。** 在波上 ∂ₜu = −cU′，∂ₜₜu = c²U″。含 ∂ₜₜ 的分量的剖面方程是 G(U, U′, U″, −cU′) − c²U″ = 0。
阻尼波方程的剖面方程是 (D − c²τ)U″ + cγ(U)U′ + f(U) = 0。它在 |c| < √(D/τ)（低于特征速度）时是二阶的。

**线性化。** 设 u = U + e^{λt}p。在随波坐标里 ∂ₜ 变成 Λ = λ − c∂_z。记 N₁ = −∂G/∂(∂ₜu)（阻尼矩阵，在波上取值），N₂ = diag(分量是否含 ∂ₜₜ)。则

  𝓛p = λ(N₁p − 2cN₂p′) + λ²N₂p，

𝓛 是剖面方程的线性化。特征值问题对 λ 是二次的。对时间一阶的分量 N₁ = 1、N₂ = 0，退回 λp = 𝓛p。
平移模 p = U′、λ = 0 仍然存在。标签的语义不变：STABLE 指 s_ess < 0 且 Re λ ≥ 0 内除平移零点外没有特征值。

**一阶形式。** P′ = (M₀ + λM₁ + λ²M₂)P。M₁ 在 p′ 的列上有 −2c·H⁻¹N₂ 一项，M₂ = H⁻¹N₂（在 p 的列上）。

**本质谱。** 端点处 det( λ²N₂ + λ(N₁± − 2icκN₂) − Σₖ A±ₖ(iκ)ᵏ ) = 0。令 μ = λ − icκ 可以消去 c，所以实部与 c 无关。
- 标量阻尼波方程：τμ² + γμ + Dκ² + m = 0，m = −f′(u±)。4τm < γ² 时 sup Re = (−γ + √(γ² − 4τm))/(2τ)，否则是 −γ/(2τ)。
- κ → ∞ 时双曲分量的曲线趋向竖直线 Re = −γ/(2τ)，不趋向 −∞。

**搜索区域的界。** 设全部分量都含 ∂ₜₜ 和 ∂ₓₓ。在静止坐标的系数下，方程是 Λ²p + γΛp = Dp″ + bp′ + ap，其中 D = A₂ + c²，b = A₁ − cN₁，a = A₀，γ = N₁。设 D 是常数对称正定矩阵。
记 w = Λp = λp − cp′，x = Re λ，取 ‖p‖ = 1，X = ‖w‖，t = ‖p′‖。有两个恒等式：

  (I)  x(‖w‖² + ⟨Dp′, p′⟩) + Re⟨γw, w⟩ = Re⟨bp′ + ap, w⟩，
  (II) ‖w‖² − ⟨Dp′, p′⟩ = 2x·Re⟨w, p⟩ + Re⟨γw, p⟩ − Re⟨bp′ + ap, p⟩。

(I) 是方程与 w 的内积（能量恒等式），(II) 是方程与 p 的内积（动能与势能的均分）。
- 由 (II)，t 被 X 控制：d_min t² ≤ X² + (2|x| + γ_∞)X + b_∞t + a_∞。
- 代入 (I)：x ≥ −δ 时 X 有界，条件是 γ_min − δ(1 + d_max/d_min) − b_∞/√d_min > 0。
- 最后 |λ| ≤ X + |c|t。

这给出一个有界矩形。它要求 δ 小于阻尼的一半左右，与本质谱的位置 −γ/(2τ) 一致。
一部分分量对时间一阶、一部分二阶的方程组没有这个界。


### 2.13 加权空间里的第二个标签

**情形。** 波的某个端点状态不稳定时，本质谱进入右半平面，波在 L² 里不稳定（例：Fisher–KPP 波前）。这种不稳定可以是对流型的：扰动在增长，同时被带离波。在指数加权的空间里它衰减。

**语义（用户 2026-11-24 确定）。** 主标签不变，仍是 L² 里的 UNSTABLE。另外给出加权空间里的标签，作为同一行的补充。

**加权空间。** 取 φ(z)，φ′(z) = a(z)，a 在两端趋于常数 a₋、a₊。空间是 {p : e^{φ}p ∈ L²}。a₊ > 0 表示要求扰动在波的前方衰减得更快。
令 p = e^{−φ}q，特征值问题的形式不变，只是 ∂_z 换成 ∂_z − a(z)：
- 二阶算子：(∂ − a)² = ∂² − 2a∂ + a² − a′，所以 Ã₂ = A₂，Ã₁ = A₁ − 2aA₂，Ã₀ = A₀ − aA₁ + (a² − a′)A₂；
- 一阶方程组：Q′ = (M + a(z)I)Q。

**加权后的本质谱。** 端点处把色散关系里的 iκ 换成 iκ − a±。两端互相独立，各取各的权。
- 标量例 u_t = u_xx + f(u)，随波坐标：sup Re = a² − ca + f′(u±)。它在 a = c/2 处最小，值为 f′(u±) − c²/4。
- 所以 f′(u₊) > 0 时，存在使本质谱稳定的权当且仅当 c > 2√f′(u₊)（线性扩展速度）。a 的允许范围是 (c ∓ √(c² − 4f′))/2 之间。

**权的选取。** 每一端：不加权已经稳定的取 a = 0；否则取使上确界最小的 a。记录允许范围。

**平移模。** U′ 属于加权空间当且仅当 e^{φ}U′ 平方可积：前方要求波的衰减率大于 a₊。
- 属于：λ = 0 仍是特征值（推进型波前）。
- 不属于：加权空间里没有平移零点（Fisher–KPP 的超临界波前：波以慢速率衰减，比权增长得慢）。

**加权空间里的标签。**
- 没有任何权能使本质谱稳定：UNSTABLE（对任何指数权都不稳定）。
- 最好的权下本质谱恰好碰到虚轴：UNCERTAIN（临界波速）。
- 否则在这个权下按 2.4 节的定义判定：STABLE、UNSTABLE 或 UNCERTAIN。


### 2.14 守恒律

**问题。** 方程有守恒形式（conservation form）：

  ∂ₜu = ∂ₓF(u, ∂ₓu, …, ∂ₓᴷ⁻¹u)，

F 是通量（flux）。例：Burgers 方程 u_t + (u²/2)ₓ = u_xx；Cahn–Hilliard 方程；Korteweg–de Vries 方程（KdV 方程）。
每个常数都是平衡点。端点处 A₀ = 0，色散曲线在 κ = 0 处经过 λ = 0。所以 s_ess ≥ 0，2.4 节的 STABLE 不可能成立。

**行波。** 剖面方程是 (F)′ + cU′ = 0。积分一次：

  F(U, U′, …) + cU = q，q 是常数。

- 两端取极限，得到跳跃条件（jump condition，即 Rankine–Hugoniot 条件）：F(u₊) − F(u₋) + c(u₊ − u₋) = 0。
- 波前（u₊ ≠ u₋）：跳跃条件决定 c，再有 q = F(u₋) + cu₋。多分量时它是 n 个方程、一个未知数，两端状态必须相容。
- 脉冲（u₊ = u₋）：跳跃条件自动成立。c 是自由参数，必须给定。
- 剖面是约化问题 v_t = F(v, v_x, …) + cv − q 的驻波，阶数是 K − 1。

**积分后的算子。** 线性化是 λp = (F_lin p)′，其中 F_lin p = Σₖ Fₖ p⁽ᵏ⁾，Fₖ = ∂F/∂U⁽ᵏ⁾，F₀ 里加上 c。令 P(z) = ∫₋∞ᶻ p，则

  λP = F_lin P′ = Σₖ Fₖ P⁽ᵏ⁺¹⁾。

- λ ≠ 0 时两个算子的特征值相同：对原方程积分得 λ∫p = 0，所以 P 在两端都衰减。
- λ = 0：平移模 p = U′ 对应 P = U − u₋。对波前，它在右端不衰减，所以 λ = 0 不是积分后算子的特征值。对脉冲，它衰减，零点保留。
- 分析的对象是积分后的算子。

**积分两次。** 设通量本身是全导数，F = ∂ₓF₂，并且 c = 0。例：Cahn–Hilliard 方程 u_t = −(u_xx + u − u³)ₓₓ。
此时剖面方程是 F₂(U, …) = q₂，阶数是 K − 2。第二个跳跃条件是 F₂(u₊) = F₂(u₋)。取 P 为 p 的二次积分，则 λP = F₂,lin P″。

**本质谱。** 记 d 为积分次数。积分后算子的色散关系是 λ = Σₖ F±ₖ (iκ)ᵏ⁺ᵈ。它没有零阶项，在 κ = 0 处 λ = 0。
- 某个 κ ≠ 0 处 Re λ > 0：UNSTABLE。例：Kuramoto–Sivashinsky 方程，λ = κ² − κ⁴ − i(u − c)κ，上确界是 1/4。
- 否则 s_ess = 0，本质谱只在原点碰到虚轴。

**权与输运。** 设 K = 2（粘性守恒律）。端点处积分后的算子是 λP = F₁P″ + F₀P′。在权 e^{az} 的空间里（2.13 节），标量情形的上确界是 F₁a² − F₀a。
- a 介于 0 和 F₀/F₁ 之间时它为负。所以 F₀± ≠ 0 时存在使本质谱离开原点的权。
- 对 u_t + f(u)ₓ = u_xx，F₀± = c − f′(u±)，即端点处特征速度相对于波的负值。Lax 条件 f′(u₋) > c > f′(u₊) 给出 a₋ < 0 < a₊。
- Burgers 激波：记 D = u₋ − u₊。两端的速率是 ∓D/4，上确界是 −D²/16。加权后的算子与 ∂² − D²/16 共轭，没有特征值。

**标签"STABLE（代数衰减）"。** 条件：
1. 积分后算子的本质谱只在原点碰到虚轴；
2. 两端都存在指数权，使积分后算子的本质谱进入左半平面；
3. 在这个加权空间里，积分后的算子在 Re λ ≥ 0 内没有谱（脉冲：除平移零点外）。

含义：对原方程，L² 里的扰动没有指数衰减率，只有代数衰减；指数局域的扰动按指数衰减（Sattinger 1976；Zumbrun 和 Howard 1998）。
确认了 Re λ > 0 的特征值时输出 UNSTABLE。

**方程组与高阶方程：闭右半平面上的行列式（第二版，2026-11-24）。**
设 d = 1，波是波前，并且两端的输运矩阵 F₀± 的特征值全是非零实数（没有特征速度等于波速）。
- 积分后算子的端点矩阵有 n 个慢特征值 μ_j = λ/α_j + O(λ²)。α_j 是 F₀± 的特征值，即相对特征速度的负值。其余特征值是快的，λ → 0 时不趋于零。
- Re λ > 0 时，慢模属于不稳定子空间当且仅当 α_j > 0。这个归属与 λ 无关。所以不稳定子空间可以连续延拓到 Re λ = 0，包括 λ = 0。
- 在虚轴上慢特征值的实部是 O(|λ|²)，在原点为零，符号不能用作判据。归属由 dμ_j/dλ 的实部的符号给出，它等于 1/α_j 的符号。
- 于是积分后算子的 Evans 函数 D 在闭右半平面上连续。对 Lax 激波，D(0) ≠ 0 对应剖面的横截性加上 Liu–Majda 型的行列式条件。
- 方程组在同一端通常同时有 α_j > 0 和 α_j < 0：一部分特征线进入激波，一部分离开。单个指数权不能同时处理两者，所以加权的办法只对标量方程有效。闭右半平面的办法不需要权。

**"STABLE（代数衰减）"的两种判定。**
- 加权法（标量二阶方程）：上面的条件 1–3。
- 闭右半平面法（方程组；高阶方程；也可用于标量方程）：D 在 Re λ ≥ 0 内没有零点，原点包括在内。

两者的含义相同（Zumbrun 和 Howard 1998；Mascia 和 Zumbrun 2003）。

**两种办法都不适用的情形。** 某一端没有输运（某个 α_j = 0；Cahn–Hilliard 的扭结属于 d = 2）；脉冲（D(0) = 0）；特征速度不是实数。此时改用 2.15 节的中性模式。


### 2.15 中性模式：色散型方程与无耗散的方程

**情形。** s_ess = 0，并且没有 2.13、2.14 节那样的权。有三类：
- 色散型（dispersive）方程。例：KdV 方程 u_t + uᵖu_x + u_xxx = 0。色散关系 λ = i(κ³ + cκ) 整条在虚轴上。
- 没有阻尼的波动方程。例：u_tt = u_xx + f(u)。静止波的本质谱是虚轴上 |Im λ| ≥ √(−f′(u±)) 的部分。
- 没有输运的守恒律（2.14 节）。

这些波的扰动没有指数衰减。"稳定"只能指"没有增长"。

**标签"STABLE（中性）"。** 含义只有一条：在 Re λ > r₀ 内没有谱。r₀ 是分辨阈值，与标签一起打印。
它不排除：
- 增长率小于 r₀ 的特征值；
- 虚轴上的特征值，包括嵌在本质谱里的；
- 原点处 Jordan 块引起的代数增长（Hamilton 型方程的零特征值，代数重数至少为 2）。

所以它比 2.4 节的 STABLE 弱，也不等于轨道稳定性（orbital stability）。UNSTABLE 的含义不变：确认了一个 Re λ > 0 的零点。

**数学对象。** 本质谱在 Re λ ≤ 0 内，所以 Evans 函数 D 在 Re λ > 0 内解析。判定的依据是 D 在矩形 [r₀, x_max] × [−y_max, y_max] 内的零点个数。

**搜索矩形。**
- 偶数阶抛物型的守恒律：2.4 节的能量估计作用在积分后的算子上，给出矩形。
- 色散型（奇数阶）和没有阻尼的方程：最高阶项不提供耗散，没有一般的估计。矩形由输入文件给出，标签的陈述限于这个矩形。

**波速不孤立的波。**
- 没有阻尼时剖面方程是 (D − c²)U″ + f(U) = 0。每个 |c| < √D 都有波（Lorentz 变换）。波速是对称参数，必须给定。
- 守恒律的脉冲对每个 c 都存在（KdV 孤立波），c 必须给定。

**别的连续对称。** 除平移外还有一个旋转对称的波（例：非线性 Schrödinger 方程的孤子）见 2.16 节。其余情形不处理。


### 2.16 带旋转对称的波

**方程。** 局部方程组 u_t = G(u, u_x, u_xx)，对时间一阶，没有约束方程。存在一对分量 (u_i, u_j)，方程对它们的旋转等变：

  G(e^{θJ}u, e^{θJ}u_x, e^{θJ}u_xx) = e^{θJ}G(u, u_x, u_xx)，

J 是这对分量上的旋转生成元。这相当于复场 ψ = u_i + iu_j 的相位不变性。
例：非线性 Schrödinger 方程（NLS 方程）iψ_t + ψ_xx + |ψ|^{2σ}ψ = 0；复 Ginzburg–Landau 方程（CGL 方程）。

**波。** u(x, t) = e^{ωtJ}U(x − ct)，ω 是频率。剖面方程是

  G(U, U′, U″) + cU′ − ωJU = 0。

在随波平移并旋转的坐标里，方程是 u_t = G − ωJu + cu_z，波是它的驻波。

**范围。** 两端状态在旋转下不变：JU± = 0，即旋转分量在两端为零。亮孤子和耗散脉冲属于这一类。
两端振幅不为零的波（暗孤子、通向平面波的波前）不在范围内。那里的端点是一圈平衡点，剖面方程在端点处不双曲，本质谱经相位模碰到原点。

**孤立与成族。** 平移和旋转各给出一族解，用两个相位条件消去。此后有两种情形：
- 耗散型（CGL）：c 和 ω 由方程选定，波是孤立的。ω 是一个非线性特征值。
- Hamilton 型（NLS）：每一对 (c, ω) 都有波，波成两参数族（振幅族和 Galilean 族）。c 和 ω 必须给定。

**线性化。** λp = 𝓛p，𝓛 = G_lin + c∂_z − ωJ。它是 2.3 节那样的算子。本质谱、Evans 函数、搜索区域的界都照旧。
- 两端状态旋转不变时，A₀± 与 J 可交换。−ωJ 只移动虚部，所以 s_ess 与 ω 无关。
- 𝓛U′ = 0 且 𝓛(JU) = 0，所以 λ = 0 至少是二重的。

**标签。**
- 耗散型（s_ess < 0）：按 2.4 节，只把"λ = 0 是单零点"换成"λ = 0 是二重零点"。即 STABLE 指：s_ess < 0；原点处恰有两个零点；Re λ ≥ 0 内没有别的零点。
- Hamilton 型（s_ess = 0）：按 2.15 节给"STABLE（中性）"或 UNSTABLE。此时 λ = 0 的代数重数是 4（两条长度为 2 的 Jordan 链）。
- 陈述的对象是随波平移并旋转的坐标里的谱。它对应轨道意义下的稳定性：扰动后的解可以沿平移和旋转漂移。


### 2.17 趋向无扩散分量的输运（趋化、趋触）

**方程。** 分量分成两组。P：有扩散的分量 u。H：自己的方程里没有 x 导数的分量 w。

  u_t = ∂ₓ( A(u, w)u_x + B(u, w)w_x ) + R(u, u_x, w, w_x)，
  w_t = g(u, w)。

B ≠ 0 表示 u 沿 w 的梯度输运。例：趋触（haptotaxis）u_t = εu_xx − χ(u m_x)_x + f(u)，m_t = μ(1 − m) − kum。m 是细胞外基质，不扩散。
对二阶导数仿射、系数只依赖 (u, w) 的方程都能写成这个形式：a(u, w)w_xx = (a w_x)_x − (a_u u_x + a_w w_x)w_x。

**困难。** w 的二阶导数出现在 u 的方程里，而 w 自己没有二阶导数。最高阶导数的系数矩阵奇异，2.2 节的一阶形式不存在。

**通量变量。** 记通量 Φ = AU′ + BW′。行波满足

  W′ = −g(U, W)/c，
  U′ = A⁻¹(Φ − BW′)，
  Φ′ = −R − cU′。

这是 (U, Φ, W) 的常微分方程组，维数是 2n_P + n_H。它要求 c ≠ 0。

**特征值问题。** 把源项取为 λp 和 λq：

  q′ = (λq − g_u p − g_w q)/c，
  p′ = A⁻¹( J − Bq′ − (δA)U′ − (δB)W′ )，
  J′ = λp − cp′ − δR。

J 是通量的线性化，δ 表示对 (p, q) 的线性化。这是 P′ = (M₀ + λM₁)P，对 λ 是线性的，不需要对波上的系数求导。
- 它与原方程的线性化等价。端点处 M₀ + λM₁ 的特征值 ν 恰是 det(A₀ + νA₁ + ν²A₂ − λ) = 0 的根。
- 标签的语义不变（2.4 节）。

**本质谱。** 色散关系由原方程的系数给出：det(Σ A±ₖ(iκ)ᵏ − λ) = 0。A₂ 奇异不妨碍。无扩散分量的色散支在 κ → ∞ 时有界：

  λ → iκc + μ，μ 是 A₀ᴴᴴ − A₀ᴴᴾ(A₂ᴾᴾ)⁻¹A₂ᴾᴴ 的特征值。

第二项来自输运。它可以起稳定作用，也可以起失稳作用。
- 趋触，基质被细胞降解（g_u < 0，B < 0）：μ 更负。
- 趋化，信号由细胞产生（g_u > 0）：输运系数大于扩散系数时 μ > 0。常数状态在小尺度上不稳定（聚集），以它为端点的波都是 UNSTABLE。

**搜索区域。** 2.4 节的能量估计不覆盖输运项。本版本没有界，矩形由输入文件给出。

### 3.2 各阶段的方法

**符号约化。** 用 SymPy 把导数替换为独立符号，求 H = ∂E/∂T 和 a⁽ᵏ⁾ = ∂E/∂U⁽ᵏ⁾，再编译成数值函数。不调用符号化简。

**远场分裂。** 对 M±(λ) 做带排序的 Schur 分解，解一个 Sylvester 方程，得到不稳定子空间的谱投影 Pᵘ 和 Pˢ = I − Pᵘ。谱投影不依赖基的选取，并且对 λ 解析。

**本质谱。** 在 κ ≥ 0 上按 asinh 间距采样，求符号矩阵的特征值，再在最大点附近做一维精化。
有效性条件：采样上限之外实部不再增大。否则标记为"高波数处增长"。
部分抛物方程组：H 对应的支在 κ → ∞ 时趋于有限的极限。这个极限按 2.4 节的公式由小矩阵直接算出，再与采样的最大值比较，取较大者。一条从下方逼近极限的支不算"增长"。

**求波。** 截断区间 [−L, L] 上的四阶配点法（SciPy `solve_bvp`，自适应网格）。
- 边界条件用投影形式：左端 C_L·Pˢ₋(c)·(Y(−L) − Y₋) = 0，右端 C_R·Pᵘ₊(c)·(Y(L) − Y₊) = 0。C 是在初始 c 处取定的常数矩阵，所以条件对 c 光滑。
- 平移用积分相位条件固定：∫ (U − U_ref)·U_ref′ dz = 0。
- c 是否为未知量由 2.2 节的 ι 决定。
- L 由两端最慢的衰减率决定，上限为 L_max。
- 初始网格：至少 241 个节点，且间距不超过 1/(2ν)，ν 是两端状态最快的空间速率。
- 检验：残差；用更严的容差重解一次，比较 c 和剖面；脉冲不得塌缩为常数状态。
- 强制检验（M2 起）：两端处剖面到端点状态的距离必须小于 10³·ε_tail。理由：投影边界条件只精确到一阶。不满足时不给标签，输出 UNCERTAIN。

有效性条件：
- 牛顿迭代依赖初始猜测。不收敛时输出 UNCERTAIN。
- 猜测表达式必须连续可微。含 Min、Max、Abs、Piecewise 的猜测被拒绝。理由：相位条件的权函数是 U_ref′；它不连续时，配点法的误差控制达不到容差，网格无限加密。

**参数延拓。** 用途：猜测只在另一个参数值处足够好；或者目标波与猜测之间隔着一个折点。
- 第一步是自然参数步：改变参数，从上一个波出发重解剖面问题。
- 以后各步是伪弧长步（pseudo-arclength step）：参数成为未知量，另加一个积分约束

    ∫ (U − U_k)·U̇ dz + (c − c_k)·ċ + (π − π_k)·π̇ = Δs，

  其中 π 是除以参数尺度后的参数，(U̇, ċ, π̇) 是过最近两个点的单位割线方向。伪弧长步可以通过折点；自然参数步在折点处失败。
- 分支上的距离：Δs² = ∫|ΔU|² dz + Δc² + Δπ²。
- 两端状态随参数用牛顿迭代跟踪，所以输入文件只需给出一个参数值处的端点。
- 步长控制：成功后乘 1.3（上限为第一步的 8 倍）；求解失败，或相邻两条割线的夹角余弦小于 0.5 时减半重做。
- 折点：相邻两步的参数增量异号。折点的参数值由三点抛物线估计。
- 区间长度：最慢衰减率变化使所需长度超过当前值的 1.2 倍时，延长区间并重解。
- 到达目标值：最后两个点跨过目标值时，在两点之间线性插值，再在目标值处重解。之后按"求波"一段的完整容差和检验再解一次。

有效性条件：
- 起点和目标必须在同一条光滑分支上。本方法不检测分岔，也不切换分支。
- 到达的是沿给定方向第一次跨过目标值的那个波。
- 割线预估要求每一步只需少量新增节点（上限 8000）；超过即视为失败并减小步长。

**Evans 函数的离散。** 在网格上对 P′ = M P 用四阶 Lobatto 配点。未知量是全部节点值，矩阵是带状的。
- 边界行取 B_L(λ) = C_L·Pˢ₋(λ)，B_R(λ) = C_R·Pᵘ₊(λ)，C 是在参考点 λ_ref 取定的常数矩阵。
- 性质 1：边界行对 λ 解析，没有极点。
- 性质 2：离散行列式的零点 = 特征值 ∪ {B_L 或 B_R 掉秩的点}。所以计数不会偏少，只可能偏多。
- 证书：γ(λ) = det(B_L C_Lᴴ)·det(B_R C_Rᴴ) 解析，且它沿围道的环绕数为零时，围道内没有掉秩点。
- 归一化：除以常系数问题的单元因子 ∏ q(±hν)，q(v) = 1 + v/2 + v²/12，ν 取遍 M±(λ) 的特征值，符号取 Re ν 的符号。这些因子在 Ω 内解析且无零点，不改变计数。
- 行列式由带状 LU 得到，只保存对数模和单位相位。
- 参考点 λ_ref 取实数，C 因此是实矩阵，离散行列式在实轴上取实值。奇偶指标用到这一点。

有效性条件：根附近 h|ν| 不大；截断区间足够长。两者分别由分辨率加倍和改变区间长度来检验。

**Evans 网格。** 记 s(z) ∈ [0, 1] 为波的相对变化率：状态各分量的导数除以该分量沿波的变化幅度，取最大分量，再按全局最大值归一。网格的局部步长为

  h(z) = h · min(K, s(z)^(−1/4))。

- 波变化最快处步长为 h；波平坦处步长放大，至多 K 倍。
- 指数 1/4 是四阶格式等分布误差的指数。
- 依据：在常系数区域，单元映射是 M 的有理函数，它精确保持 M 的不变子空间，与步长无关。离散误差来自系数沿波的变化，所以网格只需在波变化处加密。归一化因子 q(±hν) 在 Re(hν) > 0 时没有零点，所以对步长没有额外限制。
- K = 1 时退回 M1 的均匀网格，用作 A/B 对照（选项 `mesh_cap`）。

有效性条件：上述依据是启发式的。分辨率加倍和第三个分辨率的检验对分级网格同样执行。A/B 结果见第 5 节。

**围道计数。** 自适应采样：相位增量、对数模增量或中点一致性不满足时二分。
围道是矩形 [−δ, x_max] × [−y_max, y_max]。x_max、y_max 来自 2.4 节的界，各上确界在网格上数值计算。
部分抛物方程组需要 −δ > β；β < 0 时把 δ 减小到不超过 −β/2。
有效性条件：这个界只对两类结构成立：全部分量二阶且 sym A₂ 正定；或满足 2.4 节 (S1)–(S4) 的部分抛物方程组。其他结构须由用户给出区域，否则输出 UNCERTAIN。

**奇偶指标。** 在两个分辨率上各求 D(r₀) 和 D(x_max) 的符号，共 4 次求值。
- 两个分辨率都异号时，用二分法加割线法在 (r₀, x_max) 内定位一个实零点，再按与其他零点相同的规则确认（见 3.3 节）。
- D 在某点不是实数（相位的虚部超过 10⁻⁶）时，不作任何判断。

**搜根。** 把 𝓛 用中心差分离散成稀疏矩阵（非守恒形式，与 Evans 的离散无关）。在一组位移点上做移位反演的 Arnoldi 迭代，取每个位移点附近的特征值作为初值，再用 Evans 函数的割线法精化。
- 位移点分两组：实轴上从 x_max 向左按 4 倍递减；虚轴上从 4δ 向上按 4 倍递增。
- 当已定位的零点数达到矩形计数 W 时停止。完备性由 Evans 计数控制，不由差分控制。
- 差分格点数：至少使未知量总数达到 n·n_z ≈ 2400；区间很长时，取步长 0.6·h₁。
- 每个位移点的 Arnoldi 重启次数上限为 60。理由：位移点附近没有孤立特征值时，离散的本质谱到位移点的距离几乎相等，迭代不收敛；不设上限时一个位移点耗时十几秒。已收敛的特征值照常保留。上限取 200、60、20 时，第 5 节各算例的结果相同。

**独立搜根（细分）。** 差分探针没有覆盖到的零点由 Evans 函数自己找出，不需要初值：
- 对矩形求环绕数，减去其中已知零点的个数，得到未知零点数。
- 未知零点数为 1 时，从矩形中心用割线法；收敛到矩形内且不是已知零点，即接受。
- 否则沿较长的边切成两块，分别计数，递归进行。切点取在 0.382 或 0.618 等处，不取正中，以免沿实轴切开。切线穿过零点或两块之和对不上时，换一个切点。
- 小于最小尺寸的矩形仍含 m 个零点时，报告一个 m 重的候选点。
选项 `seeds="evans"` 关闭差分探针，只用这个方法（A/B 对照）。

有效性条件：
- 差分探针是位移点附近的探针，不是完整的谱。它漏掉的零点由细分补上。细分失败（围道不可分辨，或超出矩形数预算 200）时计数对不上，结果是 UNCERTAIN，不会是错误的 STABLE。
- 本质谱造成的假特征值在精化时不收敛，因而被剔除。
- 细分的代价是每个矩形至少 32 次 Evans 求值，所以只在需要时使用。

**交叉扩散的界。** sym A₂ 不定时，对缩放量 log d_j 做 Nelder–Mead 搜索：先使 sym(DA₂D⁻¹) 的最小特征值变正，再使矩形面积最小。找不到可用的 D 时，仍须由用户给出区域。
有效性条件：只搜索对角的 D。一般的满交叉扩散矩阵可能没有可用的对角缩放。

**约束方程的计算。**
- 符号层：没有时间导数的方程被识别为约束，对应分量的质量为 0。
- Evans 行列式：不需要改动，M₁ 自动带上质量。
- 第二轮的独立离散：差分矩阵的特征值问题变成广义问题 Ap = λBp，B 是对角的 0/1 矩阵。移位反演对奇异的 B 仍然适用。
- 界：按 2.7 节计算 Γ，条件 (N1)、(N2) 不成立时不给出界。

有效性条件：第一版要求用户在输入文件里写出辅助未知量和约束方程。求解器不从积分式自动识别核；遇到 `sp.Integral` 时输出 UNCERTAIN，并提示这个写法。一般的核（Fourier 变换不是有理函数）属于 B 批。

**多脉冲的计算。**
- 为什么不直接求解：两个弱相互作用脉冲的相对位置几乎不受约束，普通的剖面问题是病态的。实测：间距只能定到 10⁻³，配点网格失控增长，多数初值不收敛。
- 做法：求解 2.8 节的"钉住"问题。未知参数是 c 和 σ₂、…、σ_N；每个脉冲一个相位条件；χ 的过渡放在相邻脉冲的中点，那里解接近静息态。这个问题是良态的。
- 允许的间距：从 `separation` 出发向两侧按 (π/β)/12 的步长找 σ 的变号区间，再用 Brent 法求零点。
- 斜率 σ′：两个步长的中心差分加 Richardson 外推；两者之差作为数值误差。
- N ≥ 3：先逐个间隙求双脉冲的允许间距，再解 N 脉冲的钉住问题，用 D_j ← D_j − σ_{j+1}/σ′(D_j) 修正到 |σ| < 10⁻¹⁰。
- 之后把得到的波交给通常的两轮判定。相互作用特征值由 3.3 节"原点圆内的零点"一段处理。

有效性条件：
- 约化 λ = −σ′(D) 只是弱相互作用下的主阶。它与 Evans 零点是两条独立的路径；间距越大两者越接近（第 5.4 节）。
- 每个钉住的位置上必须确实有一个脉冲。离前一个脉冲太近时，后一个脉冲会消失，此时求解失败。
- 尾部不振荡时，σ 不变号，求解器报告找不到允许的间距。
- 多脉冲没有接入延拓。

**子类 D 的计算。** 这一类用第二个引擎。
- 分布时滞化成离散时滞：对 s 做数值积分，∫g(s)φ(s)ds ≈ Σ_q w_q φ(s_q)，w_q 含核的值。此后问题只有离散时滞 τ_q = s_q。求积节点数是离散化的参数，不是模型的一部分。
- 求积公式：复合 Gauss–Legendre，每段 16 点。从整个区间开始二分：一段上 ∫g 和 ∫g·e^{−iΩs} 的值与两个半段之和相差小于 10⁻⁷·∫|g|·(段长/总长) 时接受这一段。无穷区间在 ∫|g| 的余量小于 10⁻¹⁰·∫|g| 处截断。权重再按 ∫g 的精确值归一，使平衡点不变。
- 求积频率 Ω：公式对 e^{−μs}（|Im μ| ≤ Ω）是准确的。第一次取 Ω = 12/平均时滞。搜索矩形算出后检查 Ω ≥ y_max（驻波）或 Ω ≥ 2y_max（运动波；y_max 已含 |c|·sup κ 一项）。不满足时用 Ω = 1.25 × 所需值重建，整个分析重做，至多两次。
- 符号层：每个离散时滞项换成一个新的符号；每个分布时滞的积分 I 也换成一个符号。于是 G 是 (U, U′, U″, 这些符号) 的局部函数，符号运算的量与求积节点数无关。在波上，延迟值是 V_q = U(z + cτ_q)，I = Σ_q w_q F(V_q)，B_q = (∂G/∂I)·w_q F′(V_q)。
- 本质谱：令 μ = λ − iκc。对每个 κ，把时滞区间 [−τ_max, 0] 用 Chebyshev 点离散（一个时滞时 17 个点；多个时滞时按 0.7·(零阶项的模)·τ 增加，至多 33 个），延迟值由 Chebyshev 插值在 −τ_q 处取值。得到一个小矩阵，它最右的特征值谱精度地逼近色散关系最右的根。
- 伪特征值：这个小矩阵的其余特征值不逼近任何根。它们位于 Re ≈ −4/τ_max 附近，在真实的根更靠左时会被误当成最右的根。所以每个候选特征值都代回完整的色散关系（全部时滞）走一步牛顿：位移小于 1% 才算数。最后对最大的那个做牛顿迭代到收敛。实部低于 −4·(零阶项的模) 的根不分辨，以这个下限代替。
- 有很多时滞时，扫描 κ 用的小矩阵略去核的末段（权重 10⁻⁴ 以内的节点），牛顿校正仍用全部节点。
- 求波：先在没有时滞时用通常的求解器求出波。然后把全部时滞乘以一个因子，从 0 延拓到 1（默认 4 步，失败时减半）。每一步在均匀网格上用牛顿法解离散的剖面方程：四阶中心差分；每个平移 cτ_q 用三次 Lagrange 插值；c 是未知量，Jacobi 矩阵里含平移量对 c 的导数；相位条件以没有时滞的波为参考。误差估计来自步长加倍后的解。
- 点谱：把 𝓛₀ 和各个平移后的时滞项离散成带状矩阵 A 和 B_q。T(λ) = λ − A − Σ_q e^{−λτ_q}B_q 的行列式的零点就是离散问题的特征值。全部 B_q 的元素存成一个稀疏映射，每个 λ 只做一次稀疏乘法。沿围道数 det T(λ) 的环绕数，割线法定位。两轮判定的其余部分不变。
- 归一化：det T 除以两端常系数问题的 Szegő 因子 exp(m₋φ₋(λ) + m₊φ₊(λ))，φ(λ) 是差分符号 det(λ − a(θ) − Σ_q e^{−λτ_q}b_q(θ)) 的对数在 θ 上的平均。这个因子在离散本质谱右侧解析、无零点，不改变计数。它的作用与 Evans 引擎的单元因子相同。
- 带宽限制：谱计算的最粗网格在 |c|·τ_max 内至多 40 个节点。
- δ 的上限：有分布时滞时 δ ≤ ρ/2，ρ 是核的衰减率（由截断点处的余量估计）。
- 独立离散（第二轮和搜根的初值）：空间用二阶差分和线性插值；时滞区间用 Chebyshev 点（一个时滞 13 个，多个时滞 17 个），延迟值由插值在 −τ_q 处取值，核的末段（权重 10⁻⁴）略去。这样得到一个普通的稀疏特征值问题，不含 λ 的指数；用移位反演求位移点附近的特征值。它与行列式引擎对时滞的处理方式完全不同。

有效性条件：
- 截断区间的两端用零 Dirichlet 条件，不是精确的渐近边界条件。孤立特征值的本征函数指数衰减，误差由改变区间长度来检验。这是 D 类可信等级低一级的主要原因。
- 归一化必须有。没有它时，行列式的相位沿围道每单位长度旋转几十弧度（与区间长度成正比），围道采样会混叠。实测：一个算例的计数在最细的网格上得到 −3；改用 Szegő 因子后，求值次数从约 1500 降到约 270，计数正确。
- 本版本只处理：常数时滞（离散的或分布的）；时滞项不带导数；每个分量都有扩散项；波速孤立；分布时滞的被积函数是 g(s)·F(被延迟的未知量)。
- 分布时滞的核必须可积，平均时滞有限，并且指数衰减或紧支：截断点超过 200 倍平均时滞时报错。
- 核的截断在 Re λ < 0 处被放大：相对误差约为 10⁻¹⁰·e^{δ·截断点}。δ 取上限 ρ/2 时约为 10⁻⁵。
- 求积频率的检查是经验规则。它保证 |Im λ| ≤ y_max 且波数不超过能量估计的界时公式准确；更高的波数由扩散项压制。
- 网格是均匀的；时滞的波没有接入延拓（对其他参数）、多脉冲和自由边界。

**子类 N（一般核）的计算。** 沿用子类 D 的行列式引擎，τ = 0。
- 符号层：识别形如 ∫K(x − y)g(u(y, t))dy 或 ∫K(s)g(u(x − s, t))ds 的积分；被积函数必须是"核 × 未知量的函数"的乘积。每个积分换成一个新的符号 V。
- 截断：核在 |K| < 10⁻¹⁰·max|K| 之外取为零，得到截断半径 R。离散后的卷积因此是带状矩阵。
- 卷积的权重：四阶乘积积分。在每个网格区间上用过四个节点的三次插值代替 g(U)，核对插值多项式的积分用 Gauss 公式精确计算。核在网格点处的折点或跳跃不损失精度。权重再按核的精确质量归一，使常数状态保持为离散方程的精确平衡点。
- 带宽限制：谱计算的最粗网格在核半径内至多 40 个节点（求波的网格至多 160 个）。理由有两个：速度；以及本机 `premesh` 环境的大规模稠密运算不可用（第 7 节），而带状运算在半带宽 400 以内正常。
- 求波：先从输入文件的猜测出发直接做牛顿迭代。失败时改用同伦：从局部极限出发，把卷积取为 η·K ∗ g(U) + (1 − η)·(∫K)·g(U)，η 从 0 走到 1。
- 本质谱：K̂(κ) 用数值积分；对每个 κ 求一个 n × n 矩阵的特征值。
- 点谱：T(λ) = λ − A − C，C 是离散的非局部项。归一化同样用 Szegő 因子，符号里加上核权重的离散 Fourier 级数。
- 独立离散：二阶差分的稀疏矩阵（普通特征值问题），移位反演。

没有扩散项时（2.10 节）的不同之处：
- 符号层：G(U, V) 的局部系数只有 a₀ 和 a₁ = c。系数不依赖 U′，所以不需要从剖面方程解出 U′（c = 0 时也解不出）。
- 求波：只做从猜测出发的牛顿迭代，没有同伦。c 是未知量，相位条件不变；驻波求得 c ≈ 0。cU′ 用四阶中心差分。
- 网格：步长由核决定，求波时核半径内 160 个节点；区间半长从 max(6, 1.5 × 核半径, 12 × 猜测宽度) 起，尾部不够小时加长。
- 行列式引擎：T(λ) = λ − cD₁ − diag(a₀) − C，其余不变。Szegő 因子的符号里用 cD₁ 的差分符号。谱计算的最粗网格在核半径内 40 个节点。
- 搜索矩形：按 2.10 节的 (a)、(b)、(c) 计算，记录里写明用的是哪一个（"numerical range"、"decay from the equation"、"resolvent estimate"）。(c) 的上确界在 κ 和 Im λ 的网格上数值计算；K̂ 在数值积分分辨不了的波数上用 |K̂(κ)| ≤ TV(K)/|κ|。
- 驻波的判定：|c| ≤ 10⁻⁸ × 核的均方根宽度 × sup‖a₀‖。
- 自动搜索：长度尺度取核的均方根宽度（没有 √(D/率) 可用）。

有效性条件（没有扩散项时）：
- 全部分量都没有 x 导数。一部分分量有扩散、一部分没有的方程组不支持。
- 剖面必须光滑，并且在网格上能分辨。g′(U(z)) 的过渡层比 核半径/160 窄时精度下降：误差估计变大，可能输出 UNCERTAIN。陡的 sigmoid 配宽的核就是这种情形。
- (b) 要求核有有限的全变差，iₖ(z) 可微。

有效性条件：
- 宽核的代价高。指数核的截断半径是 23，一个算例要 2–9 秒；这类核应改用 2.7 节的辅助未知量。
- 带宽限制使宽核的网格偏粗，精度约 10⁻³（见第 5.6 节的两条路线对照）。
- 独立离散与主引擎共用同一套卷积权重（只是网格和差分阶数不同），独立性比 L 类弱。
- 本版本只处理：每个分量都有扩散项；波速孤立；积分遍及整条直线；被积函数可分离。

**只给方程时的搜索（2.11 节）。**
- 平衡点：在每个分量的范围 [−R, R] 内（默认 R = 100，选项 `equilibria_range`）取一个格点阵，近零处密、远处疏，从每个格点做牛顿迭代，再合并重复的根。一个分量时另加上符号变化给出的区间。
- 分类：对每个平衡点求 s(e)。
- 尺度：由平衡点处的系数取长度 w₀ = √(‖A₂‖/‖A₀‖) 和速度 c₀ = √(‖A₂‖·‖A₀‖)。
- 波前的猜测：双曲正切，宽度取 1.5w₀、3w₀、0.7w₀，速度初值取 0、±0.5c₀。
- 脉冲的猜测：在平衡点上加一个 sech² 形的鼓包，方向指向每一个其他平衡点，幅值取该方向的 1 倍和 0.5 倍，宽度取 1.5w₀ 和 3w₀。没有其他平衡点时沿各坐标轴。
- 每次尝试用较松的容差和较小的节点上限（时滞和卷积两类用较粗的网格），失败得快。每个方向在第一次成功后停止。
- 去重：波速和各分量的带符号极值相同的，算同一个波。
- 求到的波再交给完整的两轮判定。
- 伙伴波（只对 L 类）：标签为 UNSTABLE 的波，先关闭奇偶捷径做一次完整计数。若恰好一个不稳定特征值且为实数，就沿每个参数的两个方向做延拓，范围是该参数值的 ±100%。分支过了折点并回到原参数值时，那里的波加入清单并走完整的判定。每个方向至多 16 步；步长缩到初值的 0.2 倍以下即放弃。
- 选项 `partners`：`True`（默认，如上）、`"all"`（对每个找到的波都做）、`False`（不做）。

有效性条件：
- 多个分量时，牛顿迭代不保证找全平衡点；范围之外的平衡点不会被找到。
- 通用猜测只能到达一部分波。实测：FHN 方程的通用猜测只到达慢脉冲；快脉冲是由伙伴波搜索补上的（第 5.7 节）。
- 伙伴波搜索默认不对 STABLE 的波做。所以如果通用猜测先找到的是稳定的那一半，不稳定的那一半不会出现在清单里，除非用 `partners="all"`。
- 伙伴波搜索只走一层：伙伴的伙伴不再搜索。一条分支上有两个以上折点时，第三个波找不到。

**子类 F 的计算。**
- 求波：区间 [−L, 0] 上的 `solve_bvp`。左端用投影边界条件；右端是 n_b 个边界条件和 Stefan 条件；c 是未知量。没有相位条件。
- 默认猜测是 far + (b − far)·exp(z/width)。边界值 b 由"猜测满足边界条件"这一要求解出（对 b 的牛顿迭代）。条件是 u_j = 值时，b_j 就是这个值。
- Evans 函数：沿用同一个配点行列式，状态多一个分量 η。左端的边界行是 [C_L·Pˢ₋(λ), 0]；右端的 n + 1 行是常数行。η 分量的远场特征值为零，不进入归一化。
- 两轮判定不变，但原点圆内期望的零点数是 0，不是 1。
- 第二轮的独立离散：半直线上的中心差分，z = 0 是网格点。带边界条件的分量在该点的行是线性化的边界条件；特征值问题因此是广义的，这些行的质量为零。边界处的导数用二阶单侧差分。没有边界条件的无扩散分量在该点保留方程。
- 哪些无扩散分量带边界条件：按 ∂_z p_j 的系数在 z = 0 处的值从大到小取，取够 n_b 减去有扩散分量的个数为止。
- 边界节点差分算子的收敛阶：5 个闭式算例（Dirichlet、Robin、流入、流出、反馈）上特征值误差的比值是 3.9–4.3（网格加倍），即二阶。
- 区间长度的检验只在左端做。

有效性条件：
- 区域在边界左侧。
- 搜索界需要 2.6 节的 (F1)–(F5)。不满足时输出 UNCERTAIN 并说明原因，除非 `options['region']` 给出矩形。Evans 引擎和差分算子不需要这些条件。
- 含无扩散分量时波速不能为零。
- 边界条件的个数必须等于 k₋ᵘ，否则求波时报错（输出 UNCERTAIN）。

**加权空间（2.13 节）的计算。**
- 只在"L² 里因本质谱而 UNSTABLE"时做。先求波（此前这种情形不求波）。
- 权的搜索：每一端在 81 个 a 上扫描上确界，再在最小值附近精化；允许范围的端点用 Brent 法。
- 加权的问题是同一个问题多带两行状态：a(z) 和 a′(z)。a(z) = a₋ + (a₊ − a₋)(1 + tanh(z/ℓ))/2，ℓ = L/10。点谱与 ℓ 无关（范数等价）。
- 系数和一阶方程组按 2.13 节变换。界、Evans 引擎、差分探针、两轮判定都不改，直接作用在变换后的问题上。
- 平移模是否在空间里：在剖面上量出波在该端的衰减率，对到端点处剖面方程的特征值上，再与权的速率比较。原点圆内期望的零点数据此取 1 或 0。

有效性条件（加权空间）：
- 只做指数权；只做对空间二阶、对时间一阶的局部方程（子类 L，含部分抛物和约束分量）。
- 波的衰减率与权的速率相等时不判定（UNCERTAIN）。
- 波速不孤立的波（进入不稳定状态的波前族）必须在文件里给出波速。

**对时间二阶的方程（2.12 节）的计算。**
- 符号层：识别 ∂ₜₜu；对最高阶时间导数解出方程；把 ∂ₜu 换成 −cU′、∂ₜₜu 换成 c²U″ 得到剖面方程。阻尼矩阵 N₁ 编译成波上的函数。
- 求波：不变，用同一个剖面方程求解器。
- 本质谱：对每个 κ 把二次问题写成伴随形式（未知量 (p, λp)），求 2n 阶矩阵的特征值。含对时间一阶的分量时是广义特征值问题，无穷特征值丢掉。
- 曲线在最大波数处是否还在上升：双曲分量的曲线趋向一条竖直线，所以只在最后一段还增长超过 10⁻⁷ 时才算上升。
- Evans 引擎：端点矩阵和单元关系都加上 λ² 项。单元关系对 λ 是四次多项式（原来是二次），用 Horner 法求值。对时间一阶的方程走原来的代码，结果逐位不变。
- 独立离散：伴随线性化。未知量 (p, q = λp)，A(p, q) = λB(p, q)，A = [[0, I], [𝓛_h, −(N₁ − 2cN₂D₁)]]，B = diag(I, N₂)。用同一个移位反演探针。
- 搜索矩形：在 X 和 x 的网格上按 2.12 节的两个恒等式求可行集的上界。

有效性条件（对时间二阶）：
- 波速低于特征速度（D − c²τ 正定），否则剖面方程退化。
- 搜索界要求全部分量都含 ∂ₜₜ 和 ∂ₓₓ、D 是常数对称正定矩阵。不满足时输出 UNCERTAIN，除非给出 `options['region']`。
- 不能与自由边界、时滞、卷积、多脉冲组合。

**本质谱与零的比较（2026-11-24 修正）。**
- 判定"s_ess > 0"和"s_ess = 0"的容差是 10⁻⁹‖A₀‖ + 64ε‖Σₖ A±ₖ(iκ*)ᵏ‖。κ* 是上确界所在的波数，ε 是机器精度。
- 第二项的原因：色散曲线整条在虚轴上时，算出的实部全是舍入误差。它的大小约为 ε 乘以符号矩阵的范数，在大波数处最大（κ = 10⁴ 时约 10⁻⁸）。只用第一项时，NLS 型的方程被误判为本质谱不稳定。
- 抛物型问题的上确界在小波数处取到，第二项可以忽略，结果不变。

**守恒律（2.14 节）的计算。**
- 识别：全部导数取零时右端恒为零（每个常数都是平衡点）。
- 通量的恢复：先代入参数值。对导数阶 m 从高到低：U⁽ᵐ⁾ 的系数不得含 m 阶导数；把它对 U⁽ᵐ⁻¹⁾ 积分，得到通量的一项；减去这一项的全导数。最后的余项必须为零。否则方程不是守恒形式，输出 UNCERTAIN。
- 波速：c = −(ΔF·Δu)/(Δu·Δu)。跳跃条件的残差超过 10⁻⁸ 时拒绝。文件给了波速而与此不符时也拒绝。
- 积分两次：c = 0 且 K ≥ 3 时，对通量再做一次恢复。成功并且第二个跳跃条件成立，就取 d = 2。
- 求波：约化问题交给原来的求波程序，作为驻波求解。
- 谱：积分后的算子作为一个"方程组"交给原来的各部分。系数是 a_{k+d} = Fₖ，a₀ = … = a_{d−1} = 0。Evans 引擎、界、差分算子都不改。
- 权：只在 K = 2 时找（2.13 节的程序）。两端的上确界都为负时，在加权空间里做两轮判定。原点圆内期望的零点数：波前取 0；脉冲按平移模是否在空间里取 1 或 0。
- 其余情形进入中性模式。

有效性条件（守恒律）：
- 对时间一阶；全部方程都是守恒形式；各分量的阶数相同；没有约束方程。
- 通量必须能逐阶积分出来（每一阶的系数对同阶导数是仿射的）。
- 不能与自由边界、多脉冲、时滞、卷积组合。

**中性模式（2.15 节）的计算。**
- 阈值：r₀ = 0.01 × 两端状态系数矩阵范数的最大值。`options['neutral_threshold']` 可以覆盖它。
- 计数：三个行列式（步长 h；步长 h/2；步长 h/2 且区间缩到 0.75L），各自在矩形 [r₀, x_max] × [−y_max, y_max] 上求环绕数。三个都分辨并且都为零 → STABLE（中性）。
- 计数为正且三者一致：在细网格上细分搜根，在粗网格上重新定位。误差估计 = 两者之差 + 波的误差。实部大于 κ_m 倍误差 → UNSTABLE。
- 加密：原点处的多重零点在网格上分裂成几个，偏移量约为离散误差的方根，可以进入矩形。所以结果未确认时把步长减半再做，最多 2 次。仍未确认 → UNCERTAIN。
- 这个模式没有原点圆，没有差分探针，没有 γ 的证书。它的检验只有"两个网格加一个较短的区间"。

有效性条件（中性模式）：
- 剖面方程的两端状态必须是双曲的（波按指数趋于两端）。
- 色散型和没有阻尼的方程必须给 `options['region']`。标签只对这个矩形成立。
- 不能与自由边界、多脉冲组合。时滞和卷积两类没有接入。

**给定波速时的求波。**
- 指标 ι = 0（波速应当孤立）而文件给了波速：波速仍作为未知量，从给定值出发。求得的值与给定值相差超过 10⁻⁶ 时输出 UNCERTAIN，理由是"给定的波速不准，或波速不孤立"。
- 对时间二阶、ι = 0、给了波速：没有阻尼时，以波速为未知量的问题是奇异的。改解辅助问题 v_t = E(v, v_x, v_xx; c)，其中 c 固定为给定值，E 是剖面方程的左端。辅助问题自己的波速 d 是展开参数（unfolding parameter）：剖面方程多出一项 dU′。有解时 d = 0。|d| > 10⁻⁶ 表示这个波速没有波（有阻尼而波速给错的情形）。
- ι = 1（波按波速成族）时不变。

**闭右半平面上的行列式（2.14 节第二版）的计算。**
- 端点处的分裂。先求端点矩阵 M(λ) 的特征值。实部的绝对值大于 10⁻⁷‖M‖ 的按符号归组，与原来相同。其余的是慢模：取它们的不变子空间，把 M 和 dM/dλ = M₁ 压缩到这个子空间上。
  - 慢特征值互不相同：用压缩后的 M 的特征向量，每个按 dμ/dλ 的实部的符号归组。
  - 慢特征值重合（λ = 0）：用压缩后的 M₁ 的特征向量和特征值。
  - 某个导数的实部为零（没有输运）：拒绝。
- 判定：与中性模式相同，只是阈值取 r₀ = 0。矩形的左边在虚轴上，并经过原点。三个行列式（两个网格加一个较短的区间）的环绕数都为零 → STABLE（代数衰减）。
- 实根：计数为奇数时先在实轴上找根。从很小的正数出发，每次乘 4，直到行列式变号，再按对数对分。
  - 原因：高阶方程的搜索矩形可以比特征值大 7 个数量级以上，细分搜根到不了那个尺度。
  - 符号按相对于起点的相位取。归一化的参考点在很远处时有舍入，行列式在实轴上只在差一个常数因子的意义下是实的。
- 方法的选取（`options['conservation_method']`）：`auto`（默认）对标量二阶方程用加权法，其余用闭右半平面法；`axis` 强制后者；`weights` 只用前者。

有效性条件（闭右半平面法）：
- 波前；积分一次（d = 1）；两端的特征速度都是实数且不等于波速。
- 检验只有"两个网格加一个较短的区间"，没有差分探针的审计。
- 搜索矩形来自能量估计。高阶方程的矩形很大（薄膜方程约 10⁵ × 10⁶）；它不影响标签，只增加求值次数。

**带旋转对称的波（2.16 节）的计算。**
- 识别：对每一对阶数相同的分量，检验无穷小等变条件 DG(U)[JU] = JG(U)。检验是 4 个随机点上的数值求值，参数取文件里的值。恰有一对通过时采用它。只在 `wave` 里出现 `frequency` 或 `frequency_guess` 时启用。
- 随波坐标里的问题：由 G − ωJu 重新生成一个局部方程组，ω 是它的一个参数。谱的计算全部作用在这个方程组上，代码不改。
- 求波：两个相位条件 ∫(U − U_ref)·U_ref′ = 0 和 ∫(U − U_ref)·JU_ref = 0，两个未知标量。
  - c 和 ω 各自二选一。文件给的是猜测值：它就是未知量。文件给的是确定值：改用一个展开参数作未知量。
  - 展开后的方程是 G + cU′ − ωJU + d₁SU′ + d₂SJU = 0，S = I + J。有解时 d₁ = d₂ = 0。
  - S 的理由：梯度型问题的余核是 (U′, JU)，Hamilton 型的余核是 (J⁻¹U′, U)。它们与 SU′、SJU 的配对矩阵分别是"Gram 矩阵加反对称矩阵"和它的负值，都非奇异。对 Hamilton 型，由 Cauchy–Schwarz 不等式可直接得到 d₁ = d₂ = 0。
  - 实现：第二个相位条件和第二个未知量复用延拓里伪弧长步的接口，两个增量取零。给定波速时把方程左乘 S⁻¹，使求波程序自己的波速恰好是 d₁。
- |d₁| 或 |d₂| 超过 10⁻⁶（相对值）：给定的波速和频率下没有波，输出 UNCERTAIN。
- 孤立性的检验：c 或 ω 作为未知量求出后，把它偏移 5%，在偏移后的值上解展开问题。展开参数仍为零说明那里也有波，即波成族。此时输出 UNCERTAIN，并要求给定波速和频率。只换初值不能检验：迭代总是回到离猜测剖面最近的那个成员。
- 原点圆内预期的零点数取 2。圆内的零点多于 2 个时，离原点最近的两个是对称零点；它们的偏移量中较大的一个计入其余零点的误差。

有效性条件（旋转对称）：
- 一对分量的一个旋转对称；对时间一阶；没有约束方程；两端状态旋转不变。
- 不能与自由边界、多脉冲、延拓、时滞、卷积组合。自动搜索不可用。
- Hamilton 型没有搜索矩形的估计，矩形由文件给出。耗散型用 2.4 节的估计。

**趋向无扩散分量的输运（2.17 节）的计算。**
- 识别：只在端点处最高阶系数矩阵奇异时尝试。H 取右端不含任何 x 导数的分量，其余是 P。要求：P 都是二阶；至少一个 H 分量的二阶导数出现在别的方程里；二阶导数的系数只依赖未知量。
- 符号推导：从 G_P 读出 A、B，算出 R = G_P − ∂ₓ(AU′ + BW′)。把带源项的向量场写成状态 (U, Φ, W) 的函数。它在源项为零时是剖面方程；M₀ 是它对状态的 Jacobi 矩阵；M₁ 是它对源项的 Jacobi 矩阵，放在 U、W 所在的列。
- 求波：原来的配点求解器，状态换成 (U, Φ, W)。猜测仍按 (U, U′, W) 给出，程序用 Φ = AU′ − Bg/c 换算。
- Evans 引擎和两轮判定：不改。
- 独立离散：差分算子直接离散原方程的线性化（系数 A₀、A₁、A₂，其中 A₂ 奇异），不经过通量变量。所需的 U′、U″、W′、W″ 由剖面方程沿波算出。它和 Evans 引擎的一阶形式是两条独立的路线。
- 本质谱：κ → ∞ 的极限公式加上 −A₀ᴴᴾ(A₂ᴾᴾ)⁻¹A₂ᴾᴴ 一项。H 的方程含 P 的一阶导数、P 的方程又含 H 的二阶导数时，色散支无界，不处理。

有效性条件（输运）：
- c ≠ 0；须给非零的 `speed_guess`。
- H 分量的方程是纯反应方程。P 分量对二阶导数仿射，系数只依赖未知量。
- 搜索矩形由 `options['region']` 给出。
- 不能与自由边界、多脉冲、旋转对称、时滞、卷积组合。加权空间里的第二个标签没有接入。

**默认的搜索矩形（2026-11-24）。**
- 用途：能量估计不适用、文件也没有给矩形时（输运项；色散型；没有阻尼；一部分分量对时间一阶、一部分二阶）。
- 取法：x_max = 4S，y_max = 8S，S = sup‖A₀‖ + sup‖A₁‖ + ½ sup‖A₁′‖，上确界沿波取。
- 这是一条规则，不是界。矩形之外的谱不在陈述之内。标签是 STABLE 时带限定词"default search rectangle x_max × y_max"，与标签一起打印。UNSTABLE 不受影响：找到的根就是根。
- `options['default_region'] = False` 恢复原来的做法（没有估计就输出 UNCERTAIN）。文件给出的矩形优先。
- 核对：广义 KdV、φ⁴、Klein–Gordon、趋触、NLS、混合阶方程共 9 个算例，默认矩形给出的标签和根与手工矩形相同（5.15 节）。

**补齐后的自动找波的计算。**
- 输运：搜索用通量变量的方程组求波；平衡点和本质谱用原方程的系数。
- 没有阻尼：候选的波速固定为零，用展开参数求波（2.15 节的做法）。
- 旋转对称：每次尝试都在随波旋转的坐标里求波，频率固定为零；该坐标下的方程组只编译一次。
- 双脉冲：脉冲的宽度取剖面偏离静止状态超过最大值 2% 的区间长度。间距的初值取宽度加上 0、1、2、… 个尾部振荡的半周期；每个初值交给多脉冲求解器，它取最近的允许间距。重复的间距丢掉，凑满 3 个为止。

### 3.3 两轮判定

记 W 为矩形上的环绕数，m₀ 为原点小圆（半径 r₀）上的环绕数。

**第一轮（所有算例）。**

| 情形 | 结果 |
|---|---|
| s_ess > 0 | UNSTABLE（本质谱），终止 |
| 奇偶指标异号，且定位到的实零点满足下一行的条件 | UNSTABLE，终止。不再做矩形计数；记录中 W 和 m₀ 为空，零点列表不完整 |
| 找到零点 λ*，且 Re λ* > κ_m·误差估计，局部环绕数为 1 | UNSTABLE，终止 |
| m₀ 大于预期：按下面"原点圆内的零点"一段逐个定位和分类 | 有确认的正实部零点 → UNSTABLE；全部确认在左半平面 → 按 W 继续 |
| W = m₀ = 1 | 临时 STABLE，进入第二轮 |
| 其他（m₀ ≠ 1；W 与已定位的零点数不符；弱不稳定） | 进入第二轮 |

误差估计 = 两个分辨率下零点之差，加上波的误差乘以 ‖A₀‖。

**原点圆内的零点。** 圆内的零点数多于预期时（多脉冲的相互作用特征值；或任何恰好靠近原点的特征值）：
- 用细分搜根找出圆内的全部零点。
- 离原点最近的那个是平移零点。模型里它精确为 0，所以它的计算值就是这一带的误差。
- 其余每个零点的误差估计 = 两个分辨率之差 + 平移零点的偏移 + 波的误差。实部大于 κ_m 倍误差的是不稳定的；小于 −κ_m 倍误差的是稳定的；其余是未分辨的。
- 未分辨时加密网格再试；仍未分辨则输出 UNCERTAIN。
- 多脉冲另有约化给出的预测 −σ′(D)。Evans 零点未分辨而预测的符号明确时，采用预测，并在记录里注明来源是约化。两者符号矛盾时，该零点记为未分辨。

这一段取代了旧规则"Re λ* > r₀ 才算不稳定"。分辨的极限现在由误差估计决定，不再由圆的半径决定。

**第二轮（只对非 UNSTABLE 的结果）。** 复用第一轮的波和数据，新增：

| 检验 | 内容 |
|---|---|
| 第三个分辨率 | W 和 m₀ 不变 |
| 改变区间长度 | 左、右分别缩短，W 不变 |
| 独立离散 | 两个差分分辨率下，探针得到的特征值在 Re λ > −δ/2、|λ| > r₀ 的区域内不得出现未被解释的 |
| 掉秩证书 | γ 的环绕数为零 |
| 波的检验 | 第一轮已做 |
| 奇偶指标 | D 在 (r₀, x_max) 上是否变号，必须与已定位实零点个数的奇偶一致 |
| 原点圆内的零点 | 每个零点在最细的网格上重新定位，实部的符号不得改变 |

奇偶指标的捷径可以关闭（选项 `parity_shortcut=False`），此时第一轮总是做完整的矩形计数。

全部通过 → STABLE。发现并确认不稳定零点 → UNSTABLE。否则 → UNCERTAIN，并列出未通过的检验。

## 4. 软件规格

### 4.1 输入文件

**正式的输入格式：列表（用户 2026-11-24）。** 一个用 SymPy 书写的 Python 文件，定义列表 `problems`。列表的第 k 项描述一个方程，名字是 `eqn<k>`，除非该项自己给 `name`。每一项是一个字典，键与下面"单个问题的文件"的名字相同：

| 键 | 内容 | 是否必须 |
|---|---|---|
| `equations` | 一个 `sp.Eq`，或 `sp.Eq` 的列表（方程组） | 必须 |
| `parameters` | `{符号: 数值}`，方程里的每个参数都要有值 | 方程含参数时必须 |
| `wave` | 波的已知条件：`kind`、两端状态（`left`、`right` 或 `rest`）、`speed` | 守恒律必须给两端状态；色散型孤立波必须给静止状态和波速；其余可省 |
| `free_boundary` | 自由边界上的条件和 Stefan 条件 | 自由边界问题必须 |
| `name`、`unknowns`、`options`、`x`、`t` | 名字；分量顺序；控制量；自变量 | 可选 |

- 没有 `wave` 的项：求解器自己找波（2.11 节），该方程得到一组波。有 `wave` 的项：只算这一个波。
- 没有参数也没有 `wave` 的项可以直接写成 `sp.Eq`（方程组写成 `sp.Eq` 的列表）。
- `x` 和 `t` 省略时从方程读出：未知量写成 `u(x, t)`，且方程里有它对第二个自变量的导数。
- 一项读不进来或计算出错时，该项的 `waves` 为空并带 `note`，列表继续算下去。
- 示例：`examples/example_list.py`（11 项，覆盖 11 种情形）。输出见 4.3 节。

**单个问题的文件**（原有格式，仍然接受）。一个 Python 文件，用 SymPy 书写。必须定义的名字：

| 名字 | 内容 |
|---|---|
| `x`, `t` | 自变量符号 |
| `equations` | `sp.Eq` 的列表，未知量写成 `u(x, t)` |
| `parameters` | `{符号: 数值}` |
| `wave` | 字典：`kind`（`'front'` 或 `'pulse'`）、`left`、`right`（脉冲可只给 `rest`）、`speed` 或 `speed_guess`、可选的 `guess`、`width`、`amplitude`、`continuation` |

可选：`unknowns`（分量顺序）、`options`（覆盖 3.4 节的默认值，或给出 `region = (x_max, y_max)`）。
`guess` 是 `{未知量: 以 z 为变量的 SymPy 表达式}`，z 用 `sp.Symbol('z')`。表达式必须连续可微。

`continuation` 是字典，含义是"猜测在 `start` 处有效，目标是文件里的参数值"：

| 键 | 内容 |
|---|---|
| `parameter` | 延拓参数（符号或名字） |
| `start` | 猜测有效的参数值 |
| `direction` | 第一步的符号，+1 或 −1。缺省时朝向目标值；`start` 等于目标值时必须给出 |
| `step`、`max_steps` | 可选：第一步的参数增量；步数上限（默认 200） |

`start` 等于目标值并给出 `direction`，表示"沿分支离开，绕过折点，回到同一个参数值"，得到的是同一组参数下的另一个波。

`options` 里与 M2 有关的键：`mesh_cap`、`parity_shortcut`、`seeds`（`"fd"` 或 `"evans"`）、`L_max`。

**自由边界。** 文件另外定义 `free_boundary`，波的类型写 `'semi'`：

| 名字 | 内容 |
|---|---|
| `free_boundary['conditions']` | `sp.Eq` 的列表，在 x = s(t) 处成立。可含 `u`、`u.diff(x)` 和代表 ds/dt 的符号。有扩散的分量各一个；无扩散的分量只在特征线进入区域时给一个（2.6 节） |
| `free_boundary['speed']` | Stefan 条件的右端：ds/dt 等于这个表达式，可含 `u` 和 `u.diff(x)` |
| `free_boundary['speed_symbol']` | 可选。条件里代表 ds/dt 的符号，例如零通量条件 `sp.Eq(D*u.diff(x) + sdot*u, 0)` 里的 `sdot`。求解器把它换成 `speed` |
| `wave['far']` | x → −∞ 处的状态 |
| `wave['speed_guess']`、`wave['width']` | 速度的初值；默认猜测 far + (边界值 − far)·exp(z/width) 的衰减长度。边界值由边界条件算出 |

约定：区域是 x < s(t)。区域在右侧的问题须先把 x 换成 −x。同一个问题有多个行波时，`speed_guess` 和 `width` 决定求出哪一个。
示例：`stefan_linear.py`（Dirichlet 条件）、`stefan_robin.py`（Robin 条件）、`stefan_robin_flux.py`（条件里含 ds/dt）、`stefan_passive.py` 和 `stefan_passive_outflow.py`（无扩散分量，带条件与不带条件）。

**只给方程。** 文件里不定义 `wave`，求解器就进入搜索。示例在 `equations/` 目录。可选：`options = dict(equilibria_range=…)`。命令行用法相同：`python -m twstab equations/nagumo.py`，输出是一份清单，每个波一行。
补齐后可选的还有：`options = dict(double_pulses=3)`（列出的双脉冲个数，0 表示不列）和 `default_region`（3.2 节）。守恒律的文件必须有 `wave`，其中至少给两端状态；示例：`equations/burgers.py` 是一个没有给的例子，求解器会指出缺什么。

**卷积积分（一般核）。** 直接写 `sp.Integral(K * g(u(y, t)), (y, -sp.oo, sp.oo))`，其中 `K` 是 `x - y` 的函数，`y` 是一个 SymPy 符号；也可以写成 `sp.Integral(K(s) * g(u(x - s, t)), (s, -sp.oo, sp.oo))`。未知量用 `u = sp.Function("u")` 定义。示例：`kernel_gauss_front.py`。
没有扩散项的方程写法相同，只是方程里不出现 x 导数。示例：`nonlocal_ac_front.py`、`neural_field_bump.py`。
核的 Fourier 变换是有理函数时（指数型的核），用上一段的辅助未知量更快、更准。

**加权空间。** 不需要写什么：波在 L² 里因本质谱而不稳定时，求解器自动给出加权空间里的第二个标签，写在记录的 `weighted` 里，命令行的同一行也打印。`options = dict(weighted=False)` 关掉它。进入不稳定状态的波前要给 `wave['speed']`。示例：`fisher_kpp.py`、`nagumo_pushed.py`。

**对时间二阶。** 直接写 `u.diff(t, 2)`，可以与 `u.diff(t)` 同时出现，例如 `sp.Eq(tau * u.diff(t, 2) + u.diff(t), u.diff(x, 2) + f)`。阻尼系数可以依赖 u。示例：`hyperbolic_front.py`、`hyperbolic_pulse.py`。

**守恒律。** 方程照常书写，例如 `sp.Eq(u.diff(t) + (u**2/2).diff(x), u.diff(x, 2))`。求解器自己识别守恒形式并恢复通量。波前只给两端状态，波速由跳跃条件算出。脉冲必须给 `wave['speed']`。示例：`burgers_shock.py`、`cahn_hilliard_kink.py`、`cahn_hilliard_pulse.py`、`ks_shock.py`、`gkdv_soliton.py`。

方程组的写法相同。两端状态必须满足全部跳跃条件；可以在文件里用 SymPy 算出（见 `chemotaxis_shock.py`）。`options['conservation_method']` 选判定的办法（3.2 节）。同一对端点状态有多个波时，猜测决定求出哪一个（见 `thin_film_shock.py`）。示例另有：`burgers_passive_shock.py`、`p_system_shock.py`。

**色散型与没有阻尼的方程。** 必须给 `options = dict(region=(x_max, y_max))`。没有阻尼的波动方程还必须给 `wave['speed']`。可选 `options['neutral_threshold']`。示例：`gkdv_soliton.py`、`klein_gordon_pulse.py`、`phi4_kink.py`。
- 标签带限定词时，命令行把它打印在标签后面，例如 `STABLE (neutral: no spectrum with Re(lambda) > 0.02)`。
- 幂的指数是符号参数、而端点状态使底数为零时，导数在该处不可求值。守恒律模式先代入参数值，不受影响；其他模式里应把指数写成 Python 整数，或把非线性项写成多项式（见 `nls_soliton.py`）。

**带旋转对称的波。** 方程写成实形式：复场 ψ = u + iv 写成 u、v 两个方程。`wave` 里给 `frequency`（确定值）或 `frequency_guess`（未知量的初值）。求解器自己识别旋转的是哪一对分量。
- 孤立的波（CGL 型）：给 `frequency_guess`。波速给 `speed` 或 `speed_guess` 都可以。
- 成族的波（NLS 型）：`speed` 和 `frequency` 都必须给。
- 猜测里旋转分量不能全为零。同一组参数有多个波时，猜测决定求出哪一个。

示例：`nls_soliton.py`、`cgl_pulse.py`、`cgl_pulse_passive.py`、`cq_cgl_pulse.py`。

**趋化 / 趋触。** 方程照常书写，例如 `-chi * (u * m.diff(x)).diff(x)`。求解器自己识别这个结构。必须给非零的 `wave['speed_guess']` 和 `options['region']`。示例：`haptotaxis_front.py`、`haptotaxis_front_passive.py`、`chemotaxis_aggregation.py`。
信号有扩散的趋化模型不需要这一段：它是交叉扩散（子类 L），或在 Hopf–Cole 变换后是守恒律（`chemotaxis_shock.py`）。

**时滞。** 时滞项直接写成 `u(x, t - tau)`，其中 `u = sp.Function("u")`，`tau` 是 `parameters` 里的一个参数。其余写法不变；`wave` 的猜测描述没有时滞时的波。示例：`delay_nagumo_front.py`。
- 多个时滞：写多个这样的项，时滞各用各的参数。示例：`delay_kink_two.py`。
- 分布时滞：写 `sp.Integral(g * F, (s, a, b))`，其中 `g` 是 `s` 的函数（核），`F` 是 `u(x, t - s)` 的函数，`b` 可以是 `sp.oo`。别的因子写在积分外面。示例：`delay_kink_gamma.py`（Gamma 核）、`delay_kink_uniform.py`（有限区间）、`delay_nagumo_distributed.py`。
- 指数核也可以按线性链写成局部方程组（2.9 节），那样更快。示例：`chain_nagumo.py`。

**多脉冲。** 在脉冲的 `wave` 里加两项：`copies`（脉冲个数 N ≥ 2）和 `separation`（间距的初值；一个数，或每个间隙一个数）。`guess` 等仍描述基本脉冲。
求解器取离 `separation` 最近的允许间距。间距可以写成一个只用于选波的参数，例如 `separation=D0` 并在 `parameters` 里给 `D0` 赋值；这样命令行的 `--set D0=70` 就能选另一个双脉冲。示例：`fhn_double_pulse.py`、`fhn_triple_pulse.py`。

**非局部项（核可化约）。** 把卷积写成一个新的未知量，并在 `equations` 里加一个没有时间导数的方程。例：w = K ∗ g(u)，K = e^{−|x|}/2，写成 `sp.Eq(0, w.diff(x, 2) - w + g)`。
此时应显式给出 `unknowns`，例如 `unknowns = [u, w]`。两端状态要包含 w 的值（它等于 g(u±)·∫K）。

示例见 `problems/`。`fhn_fast_pulse.py` 和 `fhn_slow_pulse.py` 是同一个方程、同一组参数下的两个波。

### 4.3 输出记录

**正式的输出格式：列表（用户 2026-11-24）。** 输入列表的每一项对应输出列表的一项，顺序相同：

| 字段 | 内容 |
|---|---|

| `reason` | 一句话的依据 |

M2 新增：`wave.continuation`（参数、起点、步数、折点、沿分支的参数值和速度）；`pass_1.parity`（两个分辨率上的符号、是否为奇）；`pass_1.shortcut`（值为 `parity` 时，标签由奇偶指标给出，W 为空）；`pass_1.subdivision`（细分给出的候选点数）；`essential.sides.*.limit_at_infinity`。

阶段 3 新增：`weighted`（加权空间里的标签及其证据）；`conservation`（波速、通量常数、跳跃条件的残差、积分次数）；`neutral`（阈值、矩形及其来源、三个计数、根、加密的次数）；`qualifier`（STABLE 的限定词，没有限定词时不出现）；`essential.sides.*.rounding`；`wave.unfolding_parameter`。

旋转对称新增：`symmetry`（旋转的分量对、频率、原点处预期的零点数）；`wave.frequency`、`wave.frequency_is_unknown`、`wave.unfolding_parameters`。

输运新增：`taxis`（有扩散的分量、无扩散的分量、所用的形式）。

**自动搜索（第一级）的限制。**
- 双脉冲只列最近的 3 个间距；三个以上拷贝的多脉冲不自动列出。带双脉冲的方程搜索较慢（FitzHugh–Nagumo 约 11 s）。
- 默认矩形是规则，不是界（3.2 节）。
- 清单不完备（2.11 节）。
- 伙伴波搜索只对 L 类可用；自由边界、时滞、卷积三类没有延拓。
- 失败的尝试占了大部分用时。Allen–Cahn 的两个脉冲候选都不存在，32 次尝试用了约 4 秒。
- 时滞和卷积两类的搜索较慢（6–8 秒），因为每次尝试都要解一次带状的牛顿问题。

**子类 N（一般核）的限制。**
- 全部分量都有扩散项，或者全部分量都没有 x 导数；波速孤立；被积函数必须是"核 × 未知量的函数"。
- 核的截断半径必须小于 180。衰减很慢的核（代数衰减）不支持。
- 宽核慢而且精度低（约 10⁻³）。用户已决定不修 `premesh` 环境（2026-11-24），所以带宽限制保留。
- 求波可能失败：猜测不够好，而局部极限又没有相应的波。此时输出 UNCERTAIN。
- 不能与时滞、自由边界、多脉冲、延拓组合。
- 没有扩散项时：全部分量都必须没有 x 导数；求波没有同伦，完全依赖猜测。
- 没有扩散项时，陡的剖面配宽的核分辨不了（例：β = 20 的神经场脉冲），输出 UNCERTAIN 或误差估计很大。网格步长受带宽限制，不能任意加密。
- 没有扩散项且波在移动时，估计 (b)、(c) 都不成立就没有搜索矩形（例：a₀ 沿波超过 −δ）。此时输出 UNCERTAIN，除非给出 `options['region']`。
- 估计 (b) 的矩形偏高（算例里是 40，而根在 1 附近），求值次数随之增加。

**子类 D（时滞）的限制。**
- 常数时滞（离散的或分布的）；时滞项不带导数；每个分量都有扩散项；波速孤立。依赖状态的时滞不支持。
- 分布时滞的被积函数必须是 g(s)·F(被延迟的未知量)；核必须指数衰减或紧支。代数衰减的核不支持。
- 分布时滞比等价的局部写法慢 4–6 倍（运动波 3–7 秒）。指数核和 Gamma 核可以按线性链写成局部方程组，那样走第一个引擎。求解器不自动做这个改写。
- 搜索矩形需要更高的求积频率时整个分析重做一次（多 2–3 秒）。平均时滞比反应的时间尺度长很多时容易发生。
- 截断区间用零 Dirichlet 条件，可信等级比 L 类低一级。
- 均匀网格，不适合慢-快结构。
- 时滞很大时，矩形内的零点很多（τ = 3 的算例有 25 个），用时随之增加。

**多脉冲的限制。**
- 需要振荡的尾部。
- 求出的是离 `separation` 最近的那个允许间距；间距太小、后一个脉冲无法存在时求解失败。
- N ≥ 3 用了"每个脉冲只受前一个影响"的近似来给初值，最后的间距由钉住问题修正，所以波本身不依赖这个近似；但约化的预测值依赖它。
- 用时 2–7 秒，主要花在找允许的间距上（约 20 次边值问题求解）。

**约束方程（非局部）的限制。**
- 不从 `sp.Integral` 自动识别核。
- 界的条件 (N1)、(N2) 之外的结构不给出界。
- 与无扩散分量组合时没有搜索界：例如没有扩散项的神经场方程 u_t = −u + K ∗ S(u)，化约后同时有约束分量和无扩散分量。此时输出 UNCERTAIN，除非给出 `options['region']`（给出后第一个引擎可以算，例：`nonlocal_ac_passive_local.py`）。这类方程也可以不化约，直接走一般核路线（2.10 节）。
- 自由边界与约束方程的组合没有测试。

**子类 F 的限制。**
- 搜索界要求每个边界条件只含一个分量（(F1)）。耦合两个分量的条件没有界，输出 UNCERTAIN，除非给出 `options['region']`。
- 含无扩散分量时：波速不能为零；界还要求有扩散分量的方程不含无扩散分量的导数（(F3)）。
- D 型条件的界偏大，大致按 κ_D⁴ψ⁴ 增长。反馈算例的矩形约 1000 × 4000，稳定的波因此较慢（约 2 s）。
- 自动搜索对每个远端状态只列出第一个求到的半波。同一个问题的第二个半波不在清单里（例：`stefan_robin` 在 κ = 6 时 c = −4.8 的稳定半波）。自由边界的波没有接入延拓，所以伙伴波搜索也不可用。
- 没有测试流出且稳定的组合，也没有测试 (F4)、(F5) 不成立的情形（只测了 (F1) 不成立时界被拒绝）。
- 只处理单相问题。两相 Stefan 问题（边界两侧各有方程）未实现。
- 与约束方程组合时界不适用（(F2)）。

**守恒律的限制。**
- 加权法只用于标量二阶方程。方程组和高阶方程用闭右半平面法。没有输运的端点（Cahn–Hilliard）和脉冲退到中性模式，标签较弱。
- 闭右半平面法的检验只有两个网格加一个较短的区间，没有独立差分探针的审计。它的可信等级低于加权法。Burgers 激波上两者一致。
- 方程组只做了严格抛物的粘性（每个分量都有扩散）。密度方程没有扩散的情形（可压 Navier–Stokes）没有试。
- 同一对端点状态的多个波靠不同的猜测找到；求解器不枚举它们。薄膜方程的窗口内可能还有脊更高的波，没有找。
- 欠压缩激波不处理：它只对特定的端点状态存在，需要把端点状态当未知量。
- 非压缩型的激波（过压缩、欠压缩）不处理：指标不是 0 或 1 时求波程序拒绝。
- 脉冲的波速必须给定。
- 自动搜索不列出守恒律的波：每个常数都是平衡点，候选的端点状态不是有限个。
- "代数衰减"是由谱的结构得出的结论。程序不计算衰减的幂次。

**趋化 / 趋触型的限制。**
- 没有搜索矩形的估计，矩形由文件给出。
- 必须 c ≠ 0。驻波不处理。
- 无扩散分量的方程须是纯反应方程。
- 不与自由边界组合。带 Stefan 边界的趋触模型不在范围内。
- 基质不恢复的模型（m_t = −kum）：前方的本质谱在虚轴上。这种情形没有试；按现有流程它进入中性模式。
- 没有文献里的不稳定算例。不稳定的对照是被动分量（标量参考问题）和聚集模型的本质谱（闭式）。
- 求波依赖猜测。有的参数下默认猜测失败（例：χ = 5）。
- 搜索矩形用默认规则时，STABLE 只对该矩形成立。

**旋转对称的限制。**
- 只做一个旋转对称、旋转分量两端为零的波。暗孤子、通向平面波的波前、缺陷解不做。
- 两个以上独立的旋转对称被拒绝。只在联合旋转下不变的方程组识别不出来。
- Hamilton 型：原点处的零点是四重的，按离散误差的平方根分裂。参数靠近临界值时可能输出 UNCERTAIN。矩形须由文件给出。
- 孤立性的检验使耗散型的每个波多解一次边值问题（约 1 秒）。
- 同一组参数有多个脉冲时，求出哪一个取决于猜测。求解器不列出全部。
- 自动搜索只列频率为零的波；频率不为零的波不是行波，不在范围内。每次尝试都要在旋转坐标里求波，搜索较慢（7–13 s）。
- 耗散型的稳定对照来自数值文献和独立的差分算子，没有闭式结论。

**中性模式的限制。**
- 标签只说明矩形 [r₀, x_max] × [−y_max, y_max] 内没有零点。增长率低于 r₀ 的不稳定性不会被发现，参数靠近稳定性的临界值时尤其如此。
- 色散型和没有阻尼的方程没有搜索矩形的估计，矩形由用户给出。矩形外的谱不在陈述之内。
- 原点处的多重零点在网格上分裂。分裂的零点留在矩形内时输出 UNCERTAIN（例：广义 KdV 的 p = 3，文献结论是稳定）。
- 检验比两轮判定少：没有独立的差分探针，没有 γ 的证书。可信等级低一级。
- 一个旋转对称的波已有处理（2.16 节）。别的连续对称（两个以上的旋转）不给标签。
- 没有阻尼的方程，自动搜索只列驻波。族内别的波速要在文件里给定。方程不是 Lorentz 不变时，驻波的标签不代表整族。
- 剖面方程的端点不是双曲的波不处理（例：u_t = u_xx + u²(1 − u) 进入 u = 0 的波前）。

**加权空间的限制。**
- 只做指数权。代数权（临界波速 c = 2 的 KPP 波前需要）不做，那里输出 UNCERTAIN。
- 只做对空间二阶、对时间一阶的局部方程；自由边界、时滞、卷积、高阶、对时间二阶的方程不做。
- 自动搜索不列出进入不稳定状态的波前：它们按波速成族，族的说明仍是"L² 里 UNSTABLE"。要看某个波速的加权标签，须写一个给定波速的问题文件。
- 权只取上确界最小的那一个。别的权下点谱可以不同（特征值可以穿过加权本质谱的边界出现或消失）；记录里只有这一个权的结果。

**对时间二阶的方程的限制。**
- 不支持混合导数 ∂ₓ∂ₜu（强阻尼波方程）和依赖状态的惯性系数。
- 一部分分量对时间一阶、一部分二阶的方程组没有搜索界，要给 `options['region']`。
- 没有阻尼（γ = 0）的波动方程：本质谱在虚轴上，走中性模式（2.15 节）。必须给波速和 `options['region']`。
- 波速达到特征速度时剖面方程退化，不处理。
- 运动波的不稳定算例只有"被动分量"这一种构造；没有找到耦合系统的闭式对照。

**高阶方程的限制。**
- 只有偶数阶的抛物型方程有搜索界。奇数阶（KdV 型）没有界，输出 UNCERTAIN，除非给出 `options['region']`。
- 高阶的界偏大：六阶算例的矩形是 500 × 1330，而根在 1 附近。用时仍在 1 秒左右。
- 高阶分量与无扩散分量、约束方程、自由边界、时滞、卷积的组合没有界或不支持。
- 守恒形式的高阶方程（Cahn–Hilliard、Kuramoto–Sivashinsky）走守恒律模式（2.14 节）。
- 没有做 Swift–Hohenberg 的局域态：它们需要沿蛇形分支延拓。

**已知限制（M1 遗留的已划去）。**
- ~~没有延拓。~~ 已有。但延拓不检测分岔，不切换分支；起点仍需要一个足够好的猜测。
- ~~搜索区域的界只覆盖"全部分量二阶"的情形。~~ 已推广到满足 (S1)–(S4) 的部分抛物方程组。不满足时仍输出 UNCERTAIN。这个估计没有用加权范数，所以 β 取的是沿整个波的上确界，可能偏保守。
- ~~搜根只有一种方法。~~ 已有细分搜根。
- 第二轮的"独立离散"检验仍是探针，不是对整个区域的穷举。
- ~~Evans 网格是均匀的。~~ 已有分级网格。
- 截断区间是对称的 [−L, L]。慢-快脉冲只有一侧衰减得慢，对称区间浪费约一半的长度。FHN 在 ε = 0.001 时因此需要 11 s。改成不对称区间涉及多个模块，没有在 M2 做。
- c = 0 且存在无扩散分量的情形不处理（2.4 节）。
- 小谱隙的代价：FHN 的谱隙是 εγ，围道离原点和本质谱都很近，Evans 求值次数随 ε 减小而增加（ε = 0.01 时 1512 次，ε = 0.001 时 3860 次）。

**环境问题（不属于方法）。** `premesh` 环境（OpenBLAS 0.3.34）的稠密非对称特征值求解器在矩阵阶数约 400 以上会使进程崩溃；阶数 373 以下的测试正常。2026-11-24 进一步确认：1201 阶的稠密矩阵乘法、LU 分解和线性方程组求解同样崩溃，所以缺陷在较大规模的稠密 BLAS 运算上，不限于特征值求解。第 5.3 节的独立对照因此只用 300 阶以内的矩阵。本求解器因此不调用它：差分部分用稀疏移位反演，Evans 部分只用带状 LU 和小矩阵的 Schur 分解。这个环境缺陷会影响同一环境下的其他项目，建议另行修复。
