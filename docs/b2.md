# B2 numerical periodic rolls

B2 uses the one-dimensional cubic Swift–Hohenberg equation

\[
u_t=r u-(1+\partial_x^2)^2u-u^3.
\]

Generate a stationary roll with fundamental period \(2\pi/q\) on the primary branch at fixed \(q\). The exact inputs are \(q\) and the positive first cosine coefficient \(A\). The branch solves for \(r\) and the remaining odd cosine coefficients in \(\theta=qx\). Evenness fixes the origin and \(U(\theta+\pi)=-U(\theta)\) fixes the half-period symmetry. The nonzero first harmonic gives the reconstructed profile its stated fundamental period. The template currently accepts \(4/5\le q\le6/5\) and \(1/20\le A\le2/5\). These are scouting bounds. The implementation checks each returned profile numerically. [Background on Swift–Hohenberg rolls](https://doi.org/10.1007/s002200050230)

## Reproduce

Run from the repository root with the dependencies in `requirements.txt`. Use a fresh output directory for each workflow run.

~~~powershell
$env:OPENBLAS_NUM_THREADS = '1'
python -m pdegen.workflow --family B2 --out scratch/b2
python -m pdegen.workflow --family B2 --roll 11/10 1/5 --roll 11/10 2/5 --out scratch/b2-custom
python -m pdegen.generate --family B2 --out scratch/b2-specs
python -m unittest discover -s tests -v
~~~

The default cases are fixed calibration points. The seed records provenance. The canonical specification hash binds the exact branch selector, equation and eigenproblem. The workflow writes continuation iterates, final coefficients, spectrum samples and the G3 audit to the manifest-linked files. [Checked-in B2 evidence](../evidence/b2/manifest.json)

## Verification

1. Fourier Galerkin continuation uses the first harmonic as the continuation parameter and starts near \(r=(1-q^2)^2+3A^2/4\) at small amplitude. The coarse run takes eight steps with highest odd mode 11. The fine run takes sixteen steps with highest odd mode 19.
2. Compare \(r\) and the coefficients across runs. On a shifted 1024-node grid, evaluate the stationary PDE residual and the zero-fiber translation residual \(L_0U_x\). The calculated profile and residuals are floating-point evidence. Existence and branch uniqueness for the exact continuum wave remain unverified.
3. For real \(\xi\), use the Hermitian fiber \(L_\xi=r-[1+(\partial_x+i\xi)^2]^2-3U^2\) on periodic \(H^4\). Sample 65 and 129 points spanning \([-q/2,q/2]\) with Fourier cutoffs 12 and 20. Record the three leading eigenvalues, the co-periodic fiber and samples close to the phase mode. The curvature column below estimates the quadratic coefficient of the phase eigenvalue from \([\lambda(\xi)-\lambda(0)]/\xi^2\).
4. For a positive witness with a resolved margin, check the leading eigenvalue using a twisted centered finite-difference stencil at 64, 128 and 256 physical nodes. This independently discretizes the same reconstructed profile. A converged positive witness gives numerical `UNSTABLE`. Absence of a witness leaves `UNCERTAIN` until there are continuous Bloch exclusion bounds, a treatment of the phase branch at the origin and a continuum profile error bound.

All three co-periodic spectra have an observed simple translation zero with a strictly negative second eigenvalue. The unstable roll has \(\lambda\approx0.01879946\) at \(\xi=0.09453125\), with a \(2.73\times10^{-6}\) difference against the 256-node physical stencil. This is a sideband witness. The Bloch wavenumber is continuous for perturbations on the line, so the result carries no discrete open right-half-plane count.
